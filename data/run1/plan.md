# Do the eight interviews support the three hypotheses H1 to H
Claim level needed: associate. Stakes: decision-informing.

## 0 frame
- DM-02 Hypothesis tree
- FQ-03 Definitional analysis

## 1 prepare
- HE1-02 Quality of information check

## 2 analyse (independent, any order)
- CM1-05 Comparative case study
- CM1-14 Absence analysis
- HE1-14 Framework analysis
- TC1-13 Analysis of competing hypotheses

## 3 check
- CK-17 Source-span and quotation check by code
- TC1-16 Disconfirmation search
- TC1-17 Sensitivity analysis

## External material to gather in stage 1 (only what a pick needs to run)
- CM1-14 needs a reference structure. Find one from a source that is not marketing or personal opinion, show it to the user, or ask the user for it. If none is found, drop CM1-14 and say so.

## Checks by stakes tier, applied to each analysis result
- CM1-05: assumption and limitation statement, alternative explanations check, source-span citation
- CM1-14: assumption and limitation statement, source-span citation, alternative explanations check
- HE1-14: spot check, human review sample
- TC1-13: assumption and limitation statement, alternative explanations check, source-span citation

## 4 synthesise (process step, always last)
Findings form: textual. Methods offered to the user:
- convergence matrix (recommended: compares the techniques' findings and marks agreement and dissonance)
- narrative synthesis (recommended: writes the answer after the matrix)
- quantitative pooling (offered only if the user confirms that two or more findings estimate the same quantity on the same scale)
Alongside: one confidence label (high, medium or low) and a one-line reason for each conclusion.

## Answer basis (facts only, no judgements about the material)
- Material given: one source(s); content types: text. Name each source, its type and its size.
- External material gathered: reference structure for CM1-14. Name each source used.
- Techniques run, and what each used: CK-17 (the findings of the analysis); CM1-05 (the brief and the material); CM1-14 (the brief and the material); DM-02 (the brief and the material); FQ-03 (the brief and the material); HE1-02 (the brief and the material); HE1-14 (the brief and the material); TC1-13 (the brief and the material); TC1-16 (the findings of the analysis); TC1-17 (the findings of the analysis).
- Checks not done because they need a person: human review sample.
- Techniques dropped, and why; files that could not be read.

## 5 review (only if the user asks)
Held back by the limit of 10 picks: CH-13, CK-26. Offer these first.
After the user reads the synthesis, offer to reassess (at most 5 more techniques per round). If the user accepts, select again with the gaps, silences and conflicts the synthesis found, leave out techniques already run, run the new ones, and synthesise again.
