# Method card test: output specification versus no card

Time of compilation: 11 November 2026, about 13:50 AEDT.

Five techniques were run on the same eight-interview material, once with the catalogue row only (A) and once with the row plus a two to three line output specification (B). A separate agent scored each output against an eight item checklist without knowing which condition produced it. I wrote both the specifications and the checklists, so the scores may favour B. Each condition has one run per technique, so a one point gap is within noise.

## Scores (out of 8)

| Technique | A: row only | B: row plus output specification |
|---|---|---|
| TC1-13 Analysis of competing hypotheses | 8 | 8 |
| HE1-14 Framework analysis | 6 | 7 |
| CM1-14 Absence analysis | 6 | 8 |
| TC1-16 Disconfirmation search | 5 | 7 |
| CK-17 Source-span and quotation check | 8 | 7 |
| Total | 33 | 37 |

## What the differences were

- Analysis of competing hypotheses: no difference. Both met every item.
- Framework analysis: neither noted which participants gave several quotes. A also altered one quote (Q1 was shortened to 'more advanced', the source reads 'a bit more, uh, advanced').
- Absence analysis: A listed absences in general rather than per hypothesis and did not separate absence in the material from absence in what was collected. B did both.
- Disconfirmation search: A did not state what would count against each hypothesis before searching and did not name the strongest counter evidence. B did both. B left Q6 out of H3 on a reasoned judgement that the checklist counted against it.
- Quotation check: both caught the altered P3 quote, the misattributed P5 quote and the fabricated P9 quote, with no false flags. A stated its string matching method. B did not, and lost one point for that.

## Reading the result

The specification helped where the technique has a required structure that a model can skip (absence analysis, disconfirmation search). It made no difference where the technique is already well known (analysis of competing hypotheses) or where the task is mechanical (quotation check). Full method cards were not needed for any of the five. The outputs are in the out folder, and the blind labels are in blind_key.json.
