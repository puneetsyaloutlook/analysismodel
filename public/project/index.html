    Project record

    The project record is the history and the evidence behind the design. The current rules are on the process pages. Current status and open items are on the status page.

    • Decisions: a dated history of each decision, with the problem that prompted it.
    • Test evidence: the two tests run on the catalogue so far.
    • Files and change rule: which file holds what, and how to change the design without creating conflicts.
