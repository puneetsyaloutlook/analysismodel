    SA-08 Pyramid principle (Minto pyramid; governing thought with grouped supporting ideas)

    Puts a governing thought at the top, groups the supporting ideas beneath it so that each group is summarised by the idea above, and opens with situation, complication, question and answer.

    Structure the written answerEvidence: DocumentedReport technique, runs in step 8

    What it does

    Puts a governing thought at the top, groups the supporting ideas beneath it so that each group is summarised by the idea above, and opens with situation, complication, question and answer. Artefact: a pyramid of statements. Read the top statement for the answer and the next level for the reasons.

    When to use it

    Use when the conclusions must be arranged into a written answer for a reader.

    When it does not fit

    Fits when one governing answer exists. DM-01 supplies the grouping.

    Result format

    The result is a pyramid of statements.

    Method steps

    1. State the governing thought: the answer to the question, in one or two sentences, placed first.
    2. Write the setup in four parts: situation, complication, question and answer.
    3. Group the supporting points so that each group supports the governing thought. Keep groups to a small number.
    4. Order the points in each group, either as a deduction (each step follows from the one before) or as an induction (items of one kind that point to a conclusion).
    5. Test vertical logic: each point should answer why, or so what, for the level above it.
    6. Test horizontal logic: the points at one level should together be enough to answer the level above, with no overlap.
    7. Write the result: the pyramid as an indented outline, and the text in that order, answer first.

    Steps drawn from: the Monash University guide to the Minto approach for the structure of situation, complication, question and answer with the pyramid, and Minto's own description of vertical and horizontal logic as reported in secondary summaries.

    Evidence and tag basis

    Documented. A Monash University writing guide describes the Minto approach as two components: the situation, complication, question and answer setup, and the pyramid principle that arranges supporting arguments from the main recommendation down to detail. (Monash University, Business paper using the Minto approach) Minto's book (1987, updated 2010) was not opened. No test of effect on reader understanding was found.

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
