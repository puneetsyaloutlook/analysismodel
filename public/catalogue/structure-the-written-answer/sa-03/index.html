    SA-03 Structured abstract (structured summary with fixed sub-headings)

    Writes the summary under fixed sub-headings, in Hartley's version background, aim, method, results and conclusions, with a word cap.

    Structure the written answerEvidence: TestedReport technique, runs in step 8

    What it does

    Writes the summary under fixed sub-headings, in Hartley's version background, aim, method, results and conclusions, with a word cap. Artefact: a short summary with labelled parts. Read the conclusions heading for the answer and the method heading for how far to trust it.

    When to use it

    Use when the conclusions must be arranged into a written answer for a reader.

    When it does not fit

    Fits empirical studies and was unsuitable for review papers. Structured versions ran about 30 per cent longer.

    Result format

    The result is a short summary with labelled parts.

    Failure modes and limits

    Model suitabilitymodel alone
    Typical model failureFills a heading with plausible content that is not in the source because the template asks for it.
    Error sourceslanguage model
    Certainty limitsThe structure changes how the answer is read, not what the findings support. Certainty drops when a summary leaves out a limit that the findings state.

    Evidence and tag basis

    Tested. Rewritten abstracts carried more checklist information (9.7 against 5.5 of 14 items) and were rated clearer by authors (7.4 against 6.2 of 10). Earlier studies found faster searches. One author wrote and scored the versions. (Hartley, Information Research; Hartley, Keele, cogprints)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
