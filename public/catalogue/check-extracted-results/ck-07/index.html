    4. CK-07 Split-sample design for measures discovered from text (split-sample framework)

    CK-07 Split-sample design for measures discovered from text (split-sample framework)

    Discover a measure such as categories or topics in one random part of the corpus and estimate its effect in the other, and produce an effect estimate that does not overfit the discovery.

    Check extracted resultsEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: show a link between things

    What it does

    Discovers the measure (categories or topics) in one random part of the corpus and estimates the effect in the other. Artefact: an effect estimate that does not overfit the discovery. Read whether the effect persists in the estimation sample.

    When to use it

    Use when a measure found in text will be used as a treatment or outcome in an effect or comparison claim.

    When it does not fit

    Fits when a text-derived measure is the treatment or outcome in a causal claim. Only the abstract was read.

    Result format

    The result names the measure, such as categories or topics, discovered in the discovery sample and gives the effect estimate from the separate estimation sample. It states whether the effect persists in the estimation sample.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureDiscovers the categories and tests them on the same documents.
    Error sourcesinput data; data transformation; statistical assumptions
    Certainty limitsCertainty drops when the split is not random (risk of bias), when the estimation part is small (imprecision) and when identification of the effect rests on assumptions outside the technique (indirectness).

    Related techniques

    • conflicts with CK-05 Out-of-sample validation (train and test split; k-fold cross-validation; bootstrap; permutation test): both spend the single-use held-out test sample
    • should follow MM-12 Probabilistic topic modelling (LDA (latent Dirichlet allocation); STM (structural topic model); mixed-membership model): topic models are a typical way to discover the measure
    • should follow MM-14 Document clustering (computer-assisted clustering; k-means on document vectors): document clusters are a typical way to discover the measure
    • pairs with CK-14 Data leakage audit (train-test contamination check; model information sheet): a leakage audit confirms the estimation part was not seen

    Evidence and tag basis

    Documented. Estimating the latent representation on the same data "may introduce an identification problem or overfit" (2018). (Egami et al. 2018, arXiv 1802.02163)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
