    4. CK-13 Multiple-testing correction (Benjamini-Hochberg false discovery rate control; Bonferroni; Holm)

    CK-13 Multiple-testing correction (Benjamini-Hochberg false discovery rate control; Bonferroni; Holm)

    Adjust the significance threshold when many comparisons are made, and produce adjusted p-values or a list of retained results.

    Check extracted resultsEvidence: DocumentedVerification technique, runs in step 6Strongest statement: show a link between things

    What it does

    Adjusts the significance threshold when many comparisons are made. False discovery rate control keeps the expected share of false discoveries among reported results at or below a chosen level, and family-wise control limits the chance of any false positive. Artefact: adjusted p-values or a list of retained results. Read how many tests were run, not only how many passed.

    When to use it

    Use when dozens or hundreds of subgroup, theme or variable comparisons were run and you need to know which results survive.

    When it does not fit

    Fits dozens or hundreds of subgroup or theme comparisons from exploratory work. Misfit: a single pre-specified hypothesis. Family-wise methods are conservative and lose power with many tests, and false discovery rate control allows some false discoveries by design.

    Result format

    The result gives the number of tests run and the number that passed, then lists each test with its original and adjusted p-value and whether it is retained. It names the correction method used and the level it controls.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureRuns many comparisons and reports the significant ones without counting them, or defines the family of tests after the fact.
    Error sourcesinput data; statistical assumptions
    Certainty limitsCertainty drops when the number of tests run is not known (risk of bias) and when the family was defined after the results (reporting bias).
