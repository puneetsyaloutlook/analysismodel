    CK-18 Numeric and attribution recomputation by code (numeric fidelity check; deterministic recomputation)

    Extract every number, date, name and quotation from an output by code and confirm that each appears in, or can be derived from, the source, and produce a list of unmatched figures and names.

    Check extracted resultsEvidence: UnconfirmedPhase: validateClaim ceiling: describe

    What it does

    Extracts every number, date, name and quotation from an output with code and confirms that each appears in, or can be derived from, the source. Artefact: a list of unmatched figures and names for a person to resolve.

    When to use it

    Use when an output contains figures, dates, named people or attributed quotations that must be exactly right.

    When it does not fit

    Fits numerical claims and named attributions. Misfit: rounded, converted or aggregated figures, which need a defined tolerance.

    Output specification

    The result lists every number, date, name and quotation extracted from the output, with a column showing whether it appears in or can be derived from the source. It ends with the list of unmatched figures and names for a person to resolve.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureComputes totals or percentages incorrectly, or attributes a quote to the wrong speaker.
    Error sourcesinput data; data transformation
    Certainty limitsCertainty drops when tolerances are loose or undefined (imprecision) and when matched figures are used in a different sense from the source (indirectness).

    Related techniques

    • should follow PE-10 Schema-based structured extraction with an LLM (LLM (large language model) information extraction; form filling from documents): extracted amounts and dates are checked against the source
    • should follow PE-12 Model summarisation of documents (abstractive summarisation; multi-document summarisation): figures in summaries are checked
    • pairs with CK-17 Source-span and quotation check by code (quote-and-verify; extractive grounding; citation verification): quotation existence and figure matching cover different errors
