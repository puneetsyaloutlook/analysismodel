    CK-14 Data leakage audit (train-test contamination check; model information sheet)

    Confirm that no information from the test items or the outcome entered the model, prompt or features, and produce a leakage checklist and a model information sheet.

    Check extracted resultsEvidence: DocumentedVerification technique, runs in step 6Strongest statement: describe

    What it does

    Confirms that no information from the test items or the outcome entered the model, prompt or features. Artefact: a leakage checklist and a model information sheet. Read which of the eight leakage types applies.

    When to use it

    Use when a predictive or classification claim is about to be reported and you need to know whether test information leaked into development.

    When it does not fit

    Fits any predictive or classification claim. Misfit: prompt examples drawn from the evaluation set. Pre-training exposure is a further route that was not confirmed.

    Result format

    The result is a leakage checklist with one line per leakage type, marking whether it applies, together with a model information sheet. It names the leakage types that apply and says what information entered the model, prompt or features.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureCannot report what it saw in pre-training.
    Error sourcesinput data; data transformation; coder or rater judgement
    Certainty limitsCertainty drops when the development steps are not documented (risk of bias) and when pre-training exposure cannot be ruled out (indirectness).

    Related techniques

    • should follow MM-07 Supervised classification and dictionary methods (text classification; fine-tuned classifier; lexicon method): a trained classifier is the usual subject
    • should follow MM-08 LLM coding and zero-shot classification of text (LLM annotation; LLM-assisted deductive coding; few-shot classification; natural language inference classification): prompts with examples can leak evaluation items
    • pairs with CK-05 Out-of-sample validation (train and test split; k-fold cross-validation; bootstrap; permutation test): a clean split is a precondition for out-of-sample testing

    Evidence and tag basis

    Documented. Leakage errors affected 329 papers across 17 fields, and none could be detected by reading the papers alone (abstract, 2022). (Kapoor and Narayanan 2022, arXiv 2207.07048)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
