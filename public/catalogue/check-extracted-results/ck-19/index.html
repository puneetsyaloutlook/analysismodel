    CK-19 Atomic claim decomposition and scoring (FActScore; atomic fact checking)

    Split generated text into atomic facts and score the share that a reliable knowledge source supports, and produce a supported proportion and a list of unsupported facts.

    Check extracted resultsEvidence: TestedVerification technique, runs in step 6Strongest statement: describe

    What it does

    Splits generated text into atomic facts and scores the share that a reliable knowledge source supports. Artefact: the proportion of supported facts and a list of unsupported facts. Read the unsupported list.

    When to use it

    Use when a long model output contains many separate factual claims and you want a figure for how many are supported.

    When it does not fit

    Fits long outputs with many separable claims. Misfit: claims that are inferences and not facts stated in the source. The estimator uses a strong model, so the checker can share the generator's errors (inference).

    Result format

    The result lists the atomic facts split out of the generated text, each marked as supported or unsupported by the knowledge source. It gives the proportion of supported facts and ends with the list of unsupported facts.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureAccepts a plausible claim that the source does not state.
    Error sourcesinput data; language model
    Certainty limitsCertainty drops when the checker model shares the generator's errors (risk of bias) and when the knowledge source is incomplete (indirectness).

    Related techniques

    • should follow PE-12 Model summarisation of documents (abstractive summarisation; multi-document summarisation): long summaries are the usual output scored
    • pairs with CK-16 Entailment-based consistency check (textual entailment; NLI (natural language inference) consistency; SummaC; FactCC; faithfulness checking): entailment scores sentences and this technique scores atomic facts
    • pairs with CK-17 Source-span and quotation check by code (quote-and-verify; extractive grounding; citation verification): span checks confirm that supporting passages exist

    Evidence and tag basis

    Tested. The automated estimator had an error rate below 2 per cent against human scoring on the authors' biography task (2023, abstract). Do not transfer the figure to other tasks. (Min et al. 2023, arXiv 2305.14251)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
