    CK-15 Sample representativeness audit (coverage check; selection bias check)

    Compare the analysed sample with the population it claims to describe and with the steps that selected it, and produce a comparison table on known variables and a list of exclusion steps.

    Check extracted resultsEvidence: DocumentedPhase: validateClaim ceiling: describe

    What it does

    Compares the analysed sample with the population it claims to describe and with the steps that selected it. Artefact: a comparison table on known variables and a list of exclusion steps. Read the gaps between sample and population.

    When to use it

    Use when results from a sample will be read as describing a wider population or a full set of documents.

    When it does not fit

    Misfit: no known population benchmark. In LLM pipelines, retrieval or truncation steps can create selection silently (inference).

    Output specification

    The result has a comparison table of the analysed sample against the population on known variables, with the gap in each row, and a list of the exclusion steps that selected the sample. It states where the gaps between sample and population are largest.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureSummarises the documents it was given as if they were all the relevant documents.
    Error sourcesinput data; source selection
    Certainty limitsCertainty drops when the benchmark is out of date or on different definitions (indirectness) and when selection steps are undocumented (risk of bias).

    Related techniques

    • should follow PE-01 Corpus construction and sampling (document selection; search string design; sampling frame design): corpus construction records how documents entered the analysis
    • pairs with MM-06 Survey weighting and subgroup estimation (design weights; calibration; post-stratification; relative standard error): weighting is one remedy for the gaps found
    • pairs with CK-24 Review sampling design (random audit sample; stratified sample; risk-based sampling; acceptance sampling; rule of three): sampling design affects what is covered

    Evidence and tag basis

    Documented. Only the point that validation sets should be random or stratified so that they represent the corpus was verified. (Grimmer and Stewart 2013, Political Analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
