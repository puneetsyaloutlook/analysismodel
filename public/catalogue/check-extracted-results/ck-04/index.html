    CK-04 Gold-standard validation sample (ground truth set; human-coded validation set)

    Build a random or stratified human-coded subset against which model output is scored and produce a labelled set.

    Check extracted resultsEvidence: DocumentedVerification technique, runs in step 6Strongest statement: describe

    What it does

    Builds a human-coded random or stratified subset against which model output is scored. Artefact: a labelled set. Read agreement among the human coders first.

    When to use it

    Use when you need human-made labels to test or tune a model or codebook and have none yet.

    When it does not fit

    Needs categories that humans can apply. Misfit: humans cannot produce the measure reliably. Revise the codebook after ambiguities, and recheck the set with agreement statistics.

    Result format

    The result is a labelled set of items drawn at random or by stratum, with one row per item showing the item and the code each human coder gave it. It reports agreement among the human coders and lists the items on which they disagreed.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureUses a model to build the gold set, so the errors in the check match the errors in the output.
    Error sourcesinput data; coder or rater judgement; source selection
    Certainty limitsCertainty drops when coders disagree (risk of bias), when the sample is not random or stratified (indirectness) and when it is small (imprecision).

    Related techniques

    • pairs with CK-01 Inter-coder agreement statistics (percentage agreement; Cohen's kappa; weighted kappa; Scott's pi; Fleiss' kappa; Krippendorff's alpha; intercoder reliability testing): agreement statistics test whether the human coders agree
    • pairs with CK-24 Review sampling design (random audit sample; stratified sample; risk-based sampling; acceptance sampling; rule of three): the sample design controls how items are drawn

    Evidence and tag basis

    Documented. The source states that "no statistical model can repair a poorly constructed training set" and quotes about 500 documents as a rule of thumb, with 100 "probably being enough". (Grimmer and Stewart 2013, Political Analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
