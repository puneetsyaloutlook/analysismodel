    CK-12 Specification sweep across models and prompts (LLM hacking test; multiverse analysis; specification curve)

    Repeat the downstream statistical test across several models, prompts and settings, and produce error rates for false positive, false negative, wrong-sign and wrong-magnitude conclusions.

    Check extracted resultsEvidence: TestedPhase: validateClaim ceiling: describe

    What it does

    Repeats the downstream statistical test across several models, prompts and settings and reports the share of conclusions that change. Artefact: error rates for false positive, false negative, wrong-sign and wrong-magnitude conclusions. Read results near a significance threshold with extra care.

    When to use it

    Use when a significance claim rests on language model labels and you need to know how often the conclusion would change under other defensible choices.

    When it does not fit

    Use for any significance claim built on LLM labels. The multiverse and specification curve names are general knowledge and were not confirmed.

    Output specification

    The result is a table with one row per model, prompt and setting combination, showing the downstream test result, followed by error rates for false positive, false negative, wrong-sign and wrong-magnitude conclusions. It states the share of conclusions that change and names the results near the significance threshold.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureThe analyst selects the favourable prompt.
    Error sourcesinput data; language model; statistical assumptions
    Certainty limitsCertainty drops when conclusions change across specifications (inconsistency) and when human annotations are missing (risk of bias).

    Related techniques

    • should follow MM-08 LLM coding and zero-shot classification of text (LLM annotation; LLM-assisted deductive coding; few-shot classification; natural language inference classification): the labels and downstream test come from the coding step
    • pairs with CK-06 Bias correction of model labels with a human-coded subsample (design-based supervised learning (DSL); prediction-powered inference (PPI); regression estimator correction): bias correction is the remedy when the sweep shows label error matters
    • pairs with CK-13 Multiple-testing correction (Benjamini-Hochberg false discovery rate control; Bonferroni; Holm): many specifications multiply the number of tests

    Evidence and tag basis

    Tested. Across 13 million labels from 18 LLMs and 2,361 hypotheses, about 31 per cent of hypotheses reached incorrect conclusions with state-of-the-art models and about half with smaller models. A few prompt paraphrases made nearly any result significant, and human annotations were the most important of 21 safeguards (2025 preprint). (Baumann et al. 2025, arXiv 2509.08825)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
