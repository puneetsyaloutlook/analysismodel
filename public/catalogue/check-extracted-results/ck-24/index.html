    CK-24 Review sampling design (random audit sample; stratified sample; risk-based sampling; acceptance sampling; rule of three)

    Choose which outputs to inspect and how many so that the observed error rate has a stated bound, and produce an error-rate estimate with an upper bound.

    Check extracted resultsEvidence: DocumentedVerification technique, runs in step 6Strongest statement: describe

    What it does

    Chooses which outputs to inspect and how many, so that the observed error rate has a stated bound. Artefact: an error-rate estimate with an upper bound. With zero errors in n independent random items, the 95 per cent upper bound is about 3 divided by n.

    When to use it

    Use when you need to audit model output by hand and must decide how many items to review and which.

    When it does not fit

    Fits rare errors and independent items. Misfit: clustered items, or errors concentrated in a subgroup, which need stratification. No source sets a sample size for LLM output.

    Result format

    The result states how the items to inspect were chosen, the sample size and the number of errors found. It gives an error-rate estimate with an upper bound, and notes the strata used if any.

    Related techniques

    • pairs with CK-26 Independent human review of model output (expert review; adjudication; human oversight): reviewers inspect the drawn sample
    • pairs with CK-25 Error taxonomy and error analysis (failure mode analysis; confusion analysis): errors found in the sample are classified
    • pairs with CK-03 Bootstrap confidence intervals for agreement and accuracy (bootstrap resampling of items): bootstrap intervals give an alternative bound

    Evidence and tag basis

    Documented. The rule of three is read from an encyclopaedia page and is valid roughly for n above 30. The note author's arithmetic gives an upper bound near 5 per cent for 59 error-free items and near 1 per cent for 299. (Wikipedia: Rule of three (statistics); Grimmer and Stewart 2013, Political Analysis; Artstein and Poesio 2008, Inter-coder agreement for computational linguistics)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
