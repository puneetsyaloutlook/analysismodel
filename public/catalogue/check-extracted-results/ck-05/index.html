    CK-05 Out-of-sample validation (train and test split; k-fold cross-validation; bootstrap; permutation test)

    Tune prompts, rules or models on one set of items and score them on a held-out set, and produce an out-of-sample error, interval or null distribution in a validation report.

    Check extracted resultsEvidence: DocumentedVerification technique, runs in step 6Strongest statement: predict, without claiming a cause

    What it does

    Tunes prompts, rules or models on one set of items and scores them on another. Artefact: out-of-sample error, interval or null distribution. Read the gap between training and test results.

    When to use it

    Use when a model or a pattern found by search needs an honest estimate of how it performs on items it has not seen.

    When it does not fit

    Use for any model or any pattern found by search. Random splits leak when items are near-duplicates or share a source (inference).

    Result format

    The result reports the out-of-sample error, interval or null distribution for the tuned prompts, rules or model, beside the result on the training sample. It states the gap between the training and test results and says whether the held-out test sample has now been opened.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureReuses the examples that shaped the prompt as test items, reports training performance as evidence, or tests many patterns and reports the best.
    Error sourcesinput data; data transformation; statistical assumptions
    Certainty limitsCertainty drops when the split leaks (risk of bias), when the held-out part is small (imprecision) and when the future data differ from the test data (indirectness).

    Related techniques

    • conflicts with CK-07 Split-sample design for measures discovered from text (split-sample framework): both spend the single-use held-out test sample; should follow :: family:Measure and model :: the modelled result is what gets tested

    • should follow PE-03 Near-duplicate detection (shingling; MinHash; locality-sensitive hashing; text reuse detection): near-duplicates must be removed before splitting

    Evidence and tag basis

    Documented. In V-fold cross-validation all predictions are made on data out of sample. Cross-validation documentation was not opened. (Grimmer and Stewart 2013, Political Analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
