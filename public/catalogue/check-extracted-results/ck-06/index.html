    CK-06 Bias correction of model labels with a human-coded subsample (design-based supervised learning (DSL); prediction-powered inference (PPI); regression estimator correction)

    Combine model labels for all items with human labels for a random subsample so that downstream estimates and intervals stay valid, and produce a corrected estimate with an interval.

    Check extracted resultsEvidence: TestedPhase: validateClaim ceiling: associate

    What it does

    Combines model labels for all items with human labels for a random subsample, so that downstream estimates and intervals stay valid. Artefact: a corrected estimate with an interval. Read whether the conclusion survives the correction.

    When to use it

    Use when model-generated labels are used in a numeric claim or a regression and you need estimates that are not biased by label errors.

    When it does not fit

    Fits when model labels are used in a numeric claim or comparison. Misfit: no random human-coded subsample with known sampling probabilities. Correction trades Type I against Type II error.

    Output specification

    The result gives a corrected estimate with its interval, set beside the uncorrected estimate from the model labels alone. It states the size of the human-coded subsample and whether the conclusion survives the correction.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureCounts model labels as truth in a regression, or reports uncorrected label counts as population values.
    Error sourcesinput data; language model; statistical assumptions; coder or rater judgement
    Certainty limitsCertainty drops when the human subsample is not random (risk of bias), when it is small (imprecision) and when human labels are unreliable (indirectness).

    Related techniques

    • should follow MM-08 LLM coding and zero-shot classification of text (LLM annotation; LLM-assisted deductive coding; few-shot classification; natural language inference classification): model labels for all items are the input
    • should follow CK-04 Gold-standard validation sample (ground truth set; human-coded validation set): the random human-coded subsample is the correction set
    • pairs with CK-12 Specification sweep across models and prompts (LLM hacking test; multiverse analysis; specification curve): a specification sweep shows how far conclusions depend on label choices

    Evidence and tag basis

    Tested. Using surrogate labels directly gave substantial bias and invalid confidence intervals even when labels were 80 to 90 per cent accurate (2023). Prediction-powered inference gives valid intervals with no assumption about the prediction model (2023, abstract). (Egami et al. 2023, arXiv 2306.04746; Angelopoulos et al. 2023, arXiv 2301.09633; Baumann et al. 2025, arXiv 2509.08825)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
