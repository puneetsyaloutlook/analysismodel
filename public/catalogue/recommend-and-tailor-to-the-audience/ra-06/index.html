    RA-06 Audience analysis and use plan (Magenta Book use and dissemination plan; tailored messaging; reader analysis)

    Names each group that will use the answer, what information it needs, at which decision point and for what purpose, and tailors an output to each, such as a one-page summary, an infographic or a seminar.

    Recommend and tailor to the audienceEvidence: DocumentedReport technique, runs in step 8

    What it does

    Names each group that will use the answer, what information it needs, at which decision point and for what purpose, and tailors an output to each, such as a one-page summary, an infographic or a seminar. Artefact: an audience list with each group's decision point and need, and one output per group. Read whether the core finding stays the same across versions.

    When to use it

    Use when the answer must recommend an action or be tailored to an audience.

    When it does not fit

    Fits when there is more than one reader type. The guidance requires AI-generated summaries to be checked for how they represent conclusions and limitations, which guards against tailoring that changes the finding.

    Result format

    The result is an audience list with each group's decision point and need, and one output per group.

    Library checks by stakes

    Each stakes level includes the checks of the level below it. Checks that need a person apply at high stakes only, so the process leaves them out at lower stakes (decision 38). Repeatability: judgement dependent.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents audience characteristics, or changes the strength of a finding between versions.
    Error sourceslanguage model; expert opinion
    Certainty limitsA recommendation depends on information about the audience or the decision that the findings do not contain. Certainty drops when that information is assumed.

    Evidence and tag basis

    Documented. UK evaluation guidance dated May 2026. A Canadian trial found tailored messaging more effective under certain circumstances, but it was read only in a companion paper without figures. (Magenta Book, May 2026; Dobbins et al. companion paper)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
