    PJ-07 Technology S-curve analysis (logistic growth, technology substitution curve)

    Fit a logistic curve to an adoption or performance series to estimate a ceiling and an inflection date, as a draft result.

    Project forwardEvidence: UnconfirmedPrimary technique, runs in step 5.3Strongest statement: predict, without claiming a cause

    What it does

    Fits a slow, fast and saturating curve to adoption or performance. Artefact: a fitted curve with ceiling and inflection date.

    When to use it

    Use when you ask how far or how fast adoption or performance will grow and the series has passed its inflection point or a ceiling is known.

    When it does not fit

    It is fitted before the inflection point (the ceiling is then poorly determined), the metric changes meaning, or the technology is replaced instead of saturating.

    Result format

    The result is a fitted logistic curve for adoption or performance, showing the slow, fast and saturating phases. It states the ceiling and the inflection date.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureReports a ceiling from a fit made before the inflection point as if it were well determined.
    Error sourcesinput data; statistical assumptions
    Certainty limitsCertainty drops when the fit starts before the inflection point (imprecision), the ceiling is assumed (risk of bias), or the metric changes meaning (indirectness).

    Related techniques

    • pairs with PJ-01 Trend extrapolation and time-series forecasting (exponential smoothing, autoregressive integrated moving average models, trend impact analysis): plain extrapolation gives a comparison when the ceiling is uncertain
    • should follow PE-04 Data profiling and rule-based validation (data audit; data quality assessment; edit checks): a data quality report shows changes in how the metric is measured
