    PJ-21 Robust decision making, adaptive pathways and info-gap analysis

    Test many model runs or futures to find the conditions under which a strategy fails and design strategies that adapt, giving vulnerability scenarios and pathway maps with trigger points as a draft result.

    Project forwardEvidence: UnconfirmedAnalysis technique, runs in step 5.3Strongest statement: describe

    What it does

    Tests many model runs or futures to find the conditions under which a strategy fails, then designs strategies that adapt. Artefact: vulnerability scenarios and pathway maps with trigger points.

    When to use it

    Use when you have a simulation model and a decision under deep uncertainty and need strategies that adapt as conditions change.

    When it does not fit

    No quantitative performance model exists, or trigger points are not tied to something that can be monitored.

    Result format

    The result lists the vulnerability scenarios, meaning the conditions under which each strategy fails, and a pathway map for the adapted strategies. Each pathway names its trigger points.
