    PJ-17 Cross-impact analysis (cross-impact matrix)

    Adjust the probability of each event in a set according to how every other event raises or lowers it, giving adjusted event probabilities and an influence matrix as a draft result.

    Project forwardEvidence: DocumentedPhase: analyseClaim ceiling: predict without implying cause

    What it does

    Adjusts the probability of each event in a set according to how every other event raises or lowers it. Artefact: adjusted event probabilities and a matrix of influential and affected variables.

    When to use it

    Use when you have 10 to 40 linked events and need to see how their probabilities change once the links between them are taken into account.

    When it does not fit

    Conditional probabilities are guessed, the judgements are inconsistent (impossible values can result), or variables are not events.

    Output specification

    The result has a list of the events with their adjusted probabilities, and a matrix in which each cell shows how one event raises or lowers another. It names the influential variables and the affected variables.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureFills the conditional probability matrix with plausible guesses that give impossible joint values.
    Error sourcesexpert opinion; statistical assumptions
    Certainty limitsCertainty drops when judgements come from one group (risk of bias), cannot be reproduced by another group (inconsistency), or are guessed (imprecision).

    Related techniques

    • should follow PJ-04 Delphi technique (real-time Delphi, mini-Delphi): a Delphi panel supplies the initial and conditional probabilities
    • should follow PJ-06 Structured expert elicitation (IDEA protocol: investigate, discuss, estimate, aggregate): structured elicitation gives numeric ranges for the inputs
    • pairs with TC1-17 Sensitivity analysis (robustness check, leave-one-out): sensitivity analysis shows which judgements move the result

    Evidence and tag basis

    Documented. The intelligence-analysis variant depends heavily on analysts' opinion and is hard to reproduce with a different group. (Wikipedia, Cross-impact analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
