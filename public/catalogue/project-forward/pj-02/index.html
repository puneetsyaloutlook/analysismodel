    PJ-02 Reference class forecasting (outside view, base-rate forecasting) Also serves: Compare.

    Replace a bottom-up estimate with the distribution of outcomes in similar completed cases, giving a base-rate distribution and the case position in it as a draft result.

    Project forwardEvidence: TestedAnalysis technique, runs in step 5.3Strongest statement: predict, without claiming a cause

    What it does

    Replaces a bottom-up estimate with the distribution of outcomes in similar past cases. Artefact: a distribution of outcomes and the case's position within it; read the base rate first, then justify departures.

    When to use it

    Use when you are asked how long, how much or how likely for a project or event that has many comparable precedents with recorded outcomes.

    When it does not fit

    The class was chosen after seeing the answer, has only a handful of cases, or several plausible classes give very different base rates that are not reported.

    Result format

    The result is a distribution of outcomes in similar past cases and the position of the case within that distribution. It states the base rate first and then gives the justification for any departure from it.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failurePicks a reference class that already matches the preferred answer and reports one base rate without showing the rates from other plausible classes.
    Error sourcesinput data; source selection; coder or rater judgement
    Certainty limitsCertainty drops when the class has few cases (imprecision), when plausible classes disagree (inconsistency), or when past cases differ from the present case in ways that matter (indirectness).

    Related techniques

    • pairs with PJ-01 Trend extrapolation and time-series forecasting (exponential smoothing, autoregressive integrated moving average models, trend impact analysis): the outside view tests a trend extrapolation against outcomes of similar cases
    • pairs with CK-15 Sample representativeness audit (coverage check; selection bias check): a representativeness audit tests whether the chosen class covers comparable cases

    Evidence and tag basis

    Tested. In the Good Judgment Project, use of comparison classes was the only principle significantly correlated with forecasting success, as summarised by a blog (secondary). PMI describes the three steps and the method's limits where few precedents exist. (AI Impacts, summary of Good Judgment Project research; PMI, From Nobel Prize to project management: reference class forecasting)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
