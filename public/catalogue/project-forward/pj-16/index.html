    4. PJ-16 Causal layered analysis

    PJ-16 Causal layered analysis

    Examine a topic at four depths (litany, social and structural causes, worldview and myth) for the present and each alternative future, giving a four-row table as a draft result.

    Project forwardEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Examines a topic at four depths: litany, social and structural causes, worldview, and myth. Artefact: a four-row table for the present and each alternative future; the alternatives usually differ in the lower layers.

    When to use it

    Use when different groups talk about a topic in different ways and you need to see how worldviews and stories shape the alternative futures.

    When it does not fit

    The lower layers are filled with speculation unsupported by text evidence, or it is used for a technical forecast with no meaning dimension.

    Result format

    The result is a table with four rows, litany, social and structural causes, worldview and myth, and one column for the present and one for each alternative future. Each cell holds a short statement for that layer and that future, and the result says in which layers the alternatives differ.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents worldview and myth layers from general knowledge instead of quoting the supplied texts.
    Error sourcesinput data; source selection; coder or rater judgement; language model
    Certainty limitsConfidence drops when the layers rest on few texts (imprecision), when one interpreter built them (risk of bias), or when the technique is used to predict (indirectness).

    Related techniques

    • pairs with HE1-16 Discourse analysis (critical discourse analysis): discourse analysis supplies text evidence for the worldview and myth layers

    Evidence and tag basis

    Documented. Developed by Inayatullah in the early 1990s; an interpretive technique not designed to forecast, and the page contains no evaluation of results. (Wikipedia, Causal layered analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
