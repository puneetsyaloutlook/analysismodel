    PJ-10 Trajectory analysis (technological trajectories, envelope curves; term not standard)

    Track a performance metric across product generations and extend the envelope of best performance, giving a trajectory chart and rate of improvement as a draft result.

    Project forwardEvidence: UnconfirmedAnalysis technique, runs in step 5.3Strongest statement: predict, without claiming a cause

    What it does

    Tracks the path of a performance metric across product generations and extends the envelope of best performance. Artefact: a trajectory chart; read the rate of improvement and any bend.

    When to use it

    Use when you ask how fast a technology metric has improved across generations and whether that rate can be extended.

    When it does not fit

    The metric is not tied to user value, only successful variants are included, or a discontinuity is plausible.

    Result format

    The result is a trajectory chart of the performance metric across product generations, with the envelope of best performance extended. It states the rate of improvement and any bend in the trajectory.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failurePlots only the successful products and extends the line without reporting the rate of improvement or any bend.
    Error sourcesinput data; source selection; statistical assumptions
    Certainty limitsCertainty drops when the metric is not tied to user value (indirectness), when only successful variants are included (risk of bias), or when no standard method is defined for the technique.

    Related techniques

    • pairs with PJ-07 Technology S-curve analysis (logistic growth, technology substitution curve): a saturating curve covers the case where the envelope bends
    • pairs with PJ-01 Trend extrapolation and time-series forecasting (exponential smoothing, autoregressive integrated moving average models, trend impact analysis): statistical extrapolation gives intervals the envelope lacks

    Evidence and tag basis

    Unconfirmed. The note author found no single standard method under this name and advises defining it explicitly or merging it with S-curve and trend extrapolation.

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
