    CF-08 Assurance case (Goal Structuring Notation; claims, arguments and evidence)

    States a top claim, breaks it through argument strategies into sub-claims and ends each branch in a cited item of evidence, with context and assumptions recorded.

    Combine findings into conclusionsEvidence: UnconfirmedConclusion technique, runs in step 7

    What it does

    States a top claim, breaks it through argument strategies into sub-claims and ends each branch in a cited item of evidence, with context and assumptions recorded. Artefact: a goal structure diagram. Read goals with no evidence and assumptions that carry a whole branch.

    When to use it

    Use when the findings of two or more techniques must be turned into stated conclusions.

    When it does not fit

    Fits a conclusion that a third party must audit. It overlaps DM-02 and TC1-20; the new element is that every branch must end in evidence.

    Result format

    The result is a goal structure diagram.

    Library checks by stakes

    Each stakes level includes the checks of the level below it. Checks that need a person apply at high stakes only, so the process leaves them out at lower stakes (decision 38). Repeatability: judgement dependent.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureCloses every branch with a citation whether or not the evidence supports the sub-claim.
    Error sourceslanguage model; expert opinion
    Certainty limitsThe conclusion depends on the findings it combines. Certainty drops when the findings come from one technique, from the same material read the same way, or when a conflict between findings has no stated cause.

    Evidence and tag basis

    Unconfirmed. The SCSC page that opened held only a download link, so only the title of the community standard was confirmed. (GSN Community Standard version 3, title only)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
