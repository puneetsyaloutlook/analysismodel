    CF-02 Following a thread (Moran-Ellis and colleagues)

    Analyses each component for its key themes and questions, then selects a question or theme from one component and follows it across the other components.

    Combine findings into conclusionsEvidence: DocumentedConclusion technique, runs in step 7

    What it does

    Analyses each component for its key themes and questions, then selects a question or theme from one component and follows it across the other components. Artefact: a set of traced threads. Read where another component confirms, changes or contradicts the thread.

    When to use it

    Use when the findings of two or more techniques must be turned into stated conclusions.

    When it does not fit

    Needs a question raised in one component that another component can address. The originators give a visual model and no explicit steps, so a catalogue entry has to write the procedure itself and say so.

    Result format

    The result is a set of traced threads.

    Library checks by stakes

    Each stakes level includes the checks of the level below it. Checks that need a person apply at high stakes only, so the process leaves them out at lower stakes (decision 38). Repeatability: judgement dependent.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureFollows only the threads that confirm the first component.
    Error sourceslanguage model; expert opinion
    Certainty limitsThe conclusion depends on the findings it combines. Certainty drops when the findings come from one technique, from the same material read the same way, or when a conflict between findings has no stated cause.

    Evidence and tag basis

    Documented. Described in a secondary source, which attributes it to Moran-Ellis and colleagues and not, as the earlier notes said, to O'Cathain and colleagues. No test was found. (O'Cathain et al. 2010, BMJ)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
