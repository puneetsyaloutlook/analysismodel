    AO-14 Real options analysis

    Values the right but not the obligation to expand, delay, switch or abandon an investment, producing an option value added to a standard valuation.

    Assess actors, options and risksEvidence: UnconfirmedPhase: analyseClaim ceiling: predict without implying cause

    What it does

    Values the right but not the obligation to expand, delay, switch or abandon an investment. Artefact: an option value added to a standard valuation.

    When to use it

    Use when a user asks what flexibility to wait, expand or abandon a project is worth beyond its base valuation.

    When it does not fit

    Volatility is chosen to give a desired answer, or the option cannot actually be exercised.

    Output specification

    The result gives a standard valuation of the investment and an option value for the right to expand, delay, switch or abandon it, added to that valuation. It states which option is valued and lists the assumptions behind the option value.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureChooses a volatility that produces the wanted value and treats an option that cannot be exercised as valuable.
    Error sourcesinput data; statistical assumptions; expert opinion
    Certainty limitsCertainty drops because the technique is unconfirmed and no evidence on decision quality was collected, because volatility is not observable for untraded assets (imprecision), and when exercise is not feasible (indirectness).

    Related techniques

    • pairs with AO-10 Cost-benefit analysis: the option value is added to a standard valuation
    • substitutes for AO-13 Decision tree and expected value: when volatility of the asset can be estimated and decision dates are fixed, a pricing model replaces a probability tree

    Evidence and tag basis

    Unconfirmed. Theory recalled from Myers (1977) and Dixit and Pindyck (1994); not opened, and no evidence on decision quality was collected.

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
