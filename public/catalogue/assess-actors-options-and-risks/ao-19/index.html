    AO-19 Ranking uncertainty analysis (stochastic multicriteria acceptability analysis; SMAA; rank acceptability index)

    Samples weights and score uncertainty many times and reports how often each option takes each rank, giving rank acceptability indices that show how stable a multi-criteria ranking is.

    Assess actors, options and risksEvidence: DocumentedPhase: analyseClaim ceiling: describe

    What it does

    Samples criteria weights and score uncertainty many times and counts how often each option takes each rank. Artefact: rank acceptability indices and central weights per option. Read them as how far the ranking depends on the assumed weights and scores, not as the chance that an option is best.

    When to use it

    Use when options have been scored against weighted criteria, or the material supplies scores and weights, and the decision depends on how stable the ranking is.

    When it does not fit

    Have the options already been scored on weighted criteria, and does the decision depend on whether the ranking would survive different weights? If yes, use this after the scoring.

    Output specification

    The result is a table with one row per option, giving the rank acceptability index for each rank and the central weights. It states how far the ranking depends on the assumed weights and scores, and does not describe the index as the chance that an option is best.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureSamples weights evenly across the whole range, so an extreme weight on one criterion is treated as likely as a balanced set, and then reports the share of samples as a probability.
    Error sourcesinput data; statistical assumptions; expert opinion
    Certainty limitsCertainty drops when scores come from one rater (risk of bias) and when the weight ranges were set without agreement (imprecision).

    Related techniques

    • pairs with AO-12 Multi-criteria decision analysis (MCDA): multi-criteria scoring and ranking uncertainty read the same scores and weights, and the second shows how stable the first ranking is
    • pairs with TC1-17 Sensitivity analysis (robustness check, leave-one-out): sensitivity analysis varies one input at a time while this technique varies all weights together

    Evidence and tag basis

    Documented. SMAA is a published family of methods for multi-criteria decision problems with uncertain or missing information, with rank acceptability indices, central weights and confidence factors as outputs. (Lahdelma and Salminen, SMAA chapter abstract; CRAN smaa package manual)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
