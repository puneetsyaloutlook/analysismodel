    AO-11 Cost-effectiveness and cost-utility analysis

    Compares options on cost per unit of one quantified effect when benefits cannot be monetised, producing cost per unit of effect for each option.

    Assess actors, options and risksEvidence: DocumentedAnalysis technique, runs in step 5.3Strongest statement: predict, without claiming a cause

    What it does

    Compares options on cost per unit of one quantified effect when benefits cannot be monetised. Artefact: cost per unit of effect.

    When to use it

    Use when a user asks which option delivers a given outcome at the lowest cost and the benefit is not easily valued in money.

    When it does not fit

    Several outcomes matter and the single measure ignores them.

    Result format

    The result is a table with one row per option, giving its cost, the quantified effect it produces and the cost per unit of that effect. It names the single effect measure used for the comparison.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureDivides cost by an outcome that is not comparable across options and ignores outcomes outside the chosen measure.
    Error sourcesinput data; statistical assumptions; data transformation
    Certainty limitsCertainty drops when the measure omits material benefits (indirectness), when outcome estimates are imprecise, and when costs are not counted the same way across options (inconsistency).

    Related techniques

    • substitutes for AO-10 Cost-benefit analysis: when benefits cannot be monetised and one quantified outcome measure captures most of them
    • pairs with AO-12 Multi-criteria decision analysis (MCDA): criteria outside the single measure can be scored beside cost per unit of effect

    Evidence and tag basis

    Documented. Reasonable only if the measure captures most of the benefits; the Magenta Book notes it may limit decision support compared with cost-benefit analysis. (Office of Impact Analysis, cost-benefit analysis guidance note; Magenta Book, Annex A, analytical methods for use within an evaluation)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
