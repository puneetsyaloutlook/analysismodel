    HE1-15 Content analysis (conventional, directed and summative)

    Codes text into categories, then counts or interprets category use, and produces category frequencies or a category structure.

    Handle evidenceEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Codes text into categories, then counts or interprets category use. Artefact: category frequencies or a category structure; read agreement between coders where used.

    When to use it

    Use when you need to say how often topics or categories appear in a body of text.

    When it does not fit

    Meaning depends on context that categories remove.

    Result format

    The result is a category structure or a table of category frequencies, with one row per category and a count or interpretation of how often the category is used. It reports agreement between coders where more than one coder was used.

    Method steps

    1. Choose the approach. Conventional: the codes come from the text. Directed: the codes start from a theory or earlier findings. Summative: count keywords, then interpret the context of their use.
    2. Conventional: read all the data repeatedly. Highlight passages that capture key thoughts, word by word. Note first impressions. Derive codes and sort them into categories (about 10 to 15 clusters). Organise the categories into a hierarchy. Write a definition for each category and code. Choose an example passage for each.
    3. Directed: take key concepts from the theory or research as initial codes and write a definition for each. Code the data, and create new codes for text that does not fit. Re-examine uncoded text for new categories. Compare supporting and non-supporting evidence and report how often each code occurred.
    4. Summative: search for the target terms and count each one, noting who used it. Find alternative terms and count them as well. Compare counts across speakers or groups. Interpret the context in which the terms are used.
    5. Optionally examine relationships between categories. Discuss the findings against existing theory and research.
    6. Write the result: category frequencies or a category structure, with an example passage for each category. Where two coders worked, report their agreement.

    Steps drawn from: Hsieh and Shannon 2005, full text at SAGE study site.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureApplies categories inconsistently across documents and reports counts without any agreement check.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsCertainty drops with low coder agreement, a corpus that was not sampled for the question (indirectness), and category drift.

    Related techniques

    • pairs with CK-01 Inter-coder agreement statistics (percentage agreement; Cohen's kappa; weighted kappa; Scott's pi; Fleiss' kappa; Krippendorff's alpha; intercoder reliability testing): agreement between coders tests whether the categories are applied consistently
    • substitutes for MM-08 LLM coding and zero-shot classification of text (LLM annotation; LLM-assisted deductive coding; few-shot classification; natural language inference classification): when volume_class is readable by a person and manual coding is feasible

    Evidence and tag basis

    Documented. Hsieh and Shannon (2005) describe three approaches: conventional, where coding categories come directly from the text; directed, where analysis starts with a theory or relevant findings as guidance for initial codes; and summative, where keywords or content are counted and compared, followed by interpretation of the context. They give analytic procedures for each. (Hsieh and Shannon, Qualitative Health Research 2005; full text)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
