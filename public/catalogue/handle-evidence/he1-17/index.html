    HE1-17 Grounded theory coding (open, axial and selective coding; constant comparison)

    Builds categories and a theory from data through open, axial and selective coding with constant comparison and produces codes, memos and a theory.

    Handle evidenceEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: show a link between things

    What it does

    Builds categories and a theory from data through coding and constant comparison. Artefact: codes, memos and a theory.

    When to use it

    Use when no theory fits the topic and you need to build one from the data by coding and comparing as you collect.

    When it does not fit

    Ordinary coding is labelled grounded theory without iterative sampling.

    Result format

    The result has a list of codes, a set of memos, and a theory built from the categories that the coding produced. It shows how each category in the theory links back to the codes and memos.

    Method steps

    1. Sample purposively, and begin coding the first data while more is still being collected.
    2. Open coding: break the data into pieces and label each with a code for the action or process it shows. Compare incident with incident.
    3. Constant comparison: keep comparing incidents, codes and categories. Refine concepts and merge codes into categories.
    4. Memos: write notes that record decisions, ideas and links between categories, so the reasoning can be followed.
    5. Axial coding: connect categories to each other and find which fall under which.
    6. Selective coding: build a storyline that ties the categories around one central concept.
    7. Theoretical sampling and saturation: follow leads by gathering new data to fill gaps, and continue until new data adds nothing to the categories. On a fixed set of material, record the data that would fill each gap instead.
    8. Write the result: the codes, the memos and a theory built around the core category. Use the coding terms of the grounded theory genre the question names. The default is open, axial and selective coding.

    Steps drawn from: Chun Tie, Birks and Francis 2019, SAGE Open Medicine, including its comparison of coding terms across genres.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureProduces a tidy theory in one pass with no memos, and labels plain thematic coding as grounded theory.
    Error sourcesinput data; coder or rater judgement
    Certainty limitsCertainty drops when sampling was not iterative, when the theory is untested outside the data, and when a single coder worked alone (risk of bias).

    Evidence and tag basis

    Documented. Chun Tie et al. (2019) describe grounded theory as built on constant comparison, memo writing and coding, with coding terms that differ by genre: open, selective and theoretical coding in the traditional genre; open, axial and selective coding in the evolved genre; and initial, focused and theoretical coding in the constructivist genre. (Chun Tie, Birks and Francis 2019, SAGE Open Medicine)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
