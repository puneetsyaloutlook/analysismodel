    HE1-17 Grounded theory coding (open, axial and selective coding; constant comparison)

    Builds categories and a theory from data through open, axial and selective coding with constant comparison and produces codes, memos and a theory.

    Handle evidenceEvidence: UnconfirmedAnalysis technique, runs in step 5.3Strongest statement: show a link between things

    What it does

    Builds categories and a theory from data through coding and constant comparison. Artefact: codes, memos and a theory.

    When to use it

    Use when no theory fits the topic and you need to build one from the data by coding and comparing as you collect.

    When it does not fit

    Ordinary coding is labelled grounded theory without iterative sampling.

    Result format

    The result has a list of codes, a set of memos, and a theory built from the categories that the coding produced. It shows how each category in the theory links back to the codes and memos.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureProduces a tidy theory in one pass with no memos, and labels plain thematic coding as grounded theory.
    Error sourcesinput data; coder or rater judgement
    Certainty limitsCertainty drops when sampling was not iterative, when the theory is untested outside the data, and when a single coder worked alone (risk of bias).
