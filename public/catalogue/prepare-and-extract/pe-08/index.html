    PE-08 Named entity recognition (NER; entity extraction)

    Tag spans of text as people, organisations, places, dates and other types, giving a table of mentions with type and position and a tagged corpus.

    Prepare and extractEvidence: DocumentedPhase: verify and prepareClaim ceiling: describe

    What it does

    Tags spans of text as people, organisations, places, dates and other types. Artefact: a table of mentions with type and position. Read which actors recur and in what contexts.

    When to use it

    Use when you need to know which people, organisations or places are named in a body of text and in what contexts.

    When it does not fit

    Entity types must match the question. Domain terms, such as company names in filings or agency names in policy documents, are often mistagged. No domain accuracy figures were verified.

    Output specification

    The result is a table of mentions, one row per mention, giving the text span, the entity type and the position. It ends with the actors that recur and the contexts in which they appear.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureTags domain terms with the wrong type and treats each distinct spelling of a name as a separate entity.
    Error sourcesinput data; statistical assumptions; language model
    Certainty limitsCertainty drops when accuracy has not been measured for the domain (indirectness), when entity types do not fit the question (indirectness), or when names vary (inconsistency).

    Related techniques

    • pairs with IS-01 Entity resolution and linking (record linkage; entity matching; entity linking; coreference resolution; blocking): entity resolution joins mentions of one entity that appear under different names
    • pairs with CK-04 Gold-standard validation sample (ground truth set; human-coded validation set): a gold-standard sample measures tagging accuracy for the domain
    • should follow PE-03 Near-duplicate detection (shingling; MinHash; locality-sensitive hashing; text reuse detection): removing repeated documents stops one mention being counted many times

    Evidence and tag basis

    Documented. A textbook chapter on sequence labelling for named entities is listed on the contents page; the chapter was not opened. (Jurafsky and Martin, SLP3 contents)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
