    PE-11 Knowledge graph construction from text (entity-relation graph; ontology population)

    Convert resolved entities and extracted relations into a graph of typed nodes and edges, each linked to its source sentence, giving a graph with provenance as a draft result.

    Prepare and extractEvidence: DocumentedPreparation technique, runs in step 5.2Strongest statement: describe

    What it does

    Converts extracted entities and relations into a graph of typed nodes and edges, each linked to its source sentence. Artefact: a graph with provenance. Read paths between entities and areas with few or contradictory edges.

    When to use it

    Use when you need to trace paths between people, organisations or concepts reported across many documents.

    When it does not fit

    Needs a fixed ontology and kept provenance. Extraction errors compound, and duplicates of one entity stay as separate nodes. No human-agreement figures for graph quality from text were found.

    Result format

    The result is a graph of typed nodes and edges, with each edge linked to the source sentence it came from. It names the paths between entities and the areas with few or contradictory edges.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureKeeps duplicate nodes for one entity and drops the link from an edge to its source sentence.
    Error sourcesinput data; data transformation; language model
    Certainty limitsCertainty drops because extraction errors compound across steps (risk of bias), duplicate nodes remain (inconsistency), and no agreement figures exist for graph quality from text (indirectness).

    Related techniques

    • should follow PE-09 Relation and event extraction (information extraction; open information extraction; temporal expression extraction): relation and event extraction supplies the edges
    • should follow IS-01 Entity resolution and linking (record linkage; entity matching; entity linking; coreference resolution; blocking): entity resolution stops one entity becoming several nodes
    • pairs with DM-21 Social network analysis (sociogram, network analysis) Also serves: Assess actors, options and risks.: social network analysis measures the structure of the graph

    Evidence and tag basis

    Documented. The survey abstract covers creation, enrichment, quality assessment, refinement and publication, and does not mention extraction from text. (Hogan et al., Knowledge graphs, arXiv 2003.02320)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
