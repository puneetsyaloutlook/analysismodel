    PE-12 Model summarisation of documents (abstractive summarisation; multi-document summarisation)

    Write a condensed text that paraphrases the content of one or many documents, giving a summary as a draft result.

    Prepare and extractEvidence: TestedPreparation technique, runs in step 5.2Strongest statement: describe

    What it does

    Writes a condensed text that paraphrases the content of one or many documents. Artefact: a summary. Read it only beside a check of each statement against the source.

    When to use it

    Use when you need a quick orientation to a set of documents before deciding how to analyse them.

    When it does not fit

    Use for orientation, not as a finding. No verified measure for current models on multi-document corpora was found.

    Result format

    The result is a condensed text that paraphrases the content of the documents. It must be accompanied by a check of each statement in the summary against the source, and it is presented as orientation and not as a finding.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureAdds statements that the documents do not contain and under-uses information in the middle of long inputs.
    Error sourcesinput data; language model
    Certainty limitsCertainty is low because all neural summarisers tested produced hallucinated content (risk of bias) and long inputs are used unevenly (inconsistency).

    Related techniques

    • pairs with CK-17 Source-span and quotation check by code (quote-and-verify; extractive grounding; citation verification): a source-span check by code catches summary statements that no passage supports
    • pairs with CK-19 Atomic claim decomposition and scoring (FActScore; atomic fact checking): atomic claim decomposition scores each summary statement against the source

    Evidence and tag basis

    Tested. Human evaluation found substantial hallucinated content in all neural summarisation systems tested (2020). Models use information in the middle of long inputs less reliably (2023). (Maynez et al. 2020, ACL; Liu et al. 2023, Lost in the middle)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
