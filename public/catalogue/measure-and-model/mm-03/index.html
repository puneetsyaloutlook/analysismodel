    MM-03 Clustering of records (k-means; hierarchical (agglomerative) clustering; DBSCAN (density-based spatial clustering of applications with noise); HDBSCAN (hierarchical DBSCAN))

    Group records by distance or density without predefined categories and produce a cluster label per record, with centroids, a dendrogram or a noise label.

    Measure and modelEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Groups records by distance or density without predefined categories. Artefact: a cluster label per record, centroids or a dendrogram, and a noise label for density-based methods. Read cluster sizes, centroid profiles and stability across restarts.

    When to use it

    Use when you want to find natural groups among records and have no predefined segments.

    When it does not fit

    K-means assumes convex, similarly spread clusters and needs the number of clusters in advance. Ward linkage needs Euclidean distance. Density-based clustering needs a distance setting that is hard to choose. Misuse: treating clusters as natural categories when the algorithm always returns the requested number.

    Result format

    The result has a cluster label for each record, a table of cluster sizes and centroids or a dendrogram, and a noise label where a density-based method was used. It reports the profile of each cluster and its stability across restarts.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents segment descriptions that the centroids do not support, or fits a pattern to noise.
    Error sourcesinput data; data transformation; statistical assumptions
    Certainty limitsCertainty drops when clusters change across restarts, algorithms or scaling choices (inconsistency) and when cluster labels are read as real categories (indirectness).

    Related techniques

    • pairs with CK-09 Cluster validation indexes (silhouette score; adjusted Rand index; adjusted mutual information; V-measure; stability analysis): validation indexes compare cluster numbers and algorithms
    • should follow MM-04 Dimensionality reduction (PCA (principal component analysis); factor analysis; non-negative matrix factorisation): reducing many correlated fields can stabilise distance-based clusters
    • should follow PE-04 Data profiling and rule-based validation (data audit; data quality assessment; edit checks): unit and range problems distort distances

    Evidence and tag basis

    Documented. The documentation states that k-means inertia "assumes that clusters are convex and isotropic". (scikit-learn clustering)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
