    MM-12 Probabilistic topic modelling (LDA (latent Dirichlet allocation); STM (structural topic model); mixed-membership model)

    Model each document as a mixture of topics and each topic as a distribution over words, and produce topic word lists and document-topic proportions.

    Measure and modelEvidence: TestedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Models each document as a mixture of topics and each topic as a distribution over words. Artefact: topic word lists and document-topic proportions. Read top words, exemplar documents, and proportions over time or by source. The label is the analyst's interpretation.

    When to use it

    Use when you have a large set of long texts and want to discover what they talk about, with no fixed categories.

    When it does not fit

    Fits long texts that contain several topics, when discovery and not fixed coding is wanted. Misfit: short texts, unstable runs, uninterpretable topics. Validation needs semantic, predictive and convergent evidence.

    Result format

    The result has a word list for each topic and the topic proportions for each document, with the proportions shown over time or by source. It gives exemplar documents for each topic and a label for each topic that is stated to be the analyst's interpretation.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureLabels word lists with confident themes and overstates a theme found in few documents.
    Error sourcesinput data; data transformation; statistical assumptions; coder or rater judgement
    Certainty limitsCertainty drops when topics change across runs or topic counts (inconsistency), when labels rest on top words only (risk of bias) and when topics have no external validation (indirectness).

    Related techniques

    • should follow PE-02 Preprocessing sensitivity testing (text cleaning; tokenisation; stopword removal; stemming; boilerplate removal; preText): cleaning rules change topics, so sensitivity to them should be known
    • pairs with CK-08 Semantic, predictive and convergent validity checks (construct validity checks): semantic, predictive and convergent checks validate topics
    • substitutes for MM-13 Embedding-based topic modelling (BERTopic; Top2Vec; clustering-based topic models): when documents are long and multi-topic and the volume class is needs automation

    Evidence and tag basis

    Tested. Models that score better on held-out likelihood "may infer less semantically meaningful topics" in large user studies (2009). LDA assumes each document is a mixture over a shared topic set, and STM adds document covariates such as time. (Chang et al. 2009, NeurIPS; Blei et al. 2003, Latent Dirichlet allocation; Roberts, Stewart and Tingley, structural topic models; Grimmer and Stewart 2013, Political Analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
