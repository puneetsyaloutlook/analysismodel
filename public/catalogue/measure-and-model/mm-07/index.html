    MM-07 Supervised classification and dictionary methods (text classification; fine-tuned classifier; lexicon method)

    Assign documents to predefined categories using human-labelled examples or word lists and produce coded documents with confidence and a confusion matrix.

    Measure and modelEvidence: TestedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Assigns documents to predefined categories using human-labelled examples or word lists. Artefact: labels with confidence and a confusion matrix against human labels not used in training. Read precision (the share of assigned labels that are correct) and recall (the share of true cases found) for each category.

    When to use it

    Use when you have fixed categories and labelled examples, or a validated word list, and need to label many documents.

    When it does not fit

    Fits fixed, defined categories that humans can code reliably. Misfit: imbalanced or overlapping categories, or training data from another period or source. Dictionaries need explicit validation because word lists fail across domains.

    Result format

    The result has a label and a confidence value for each document, and a confusion matrix against human labels that were not used in training. It reports precision and recall for each category.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureReports overall accuracy and does not show poor performance on rare categories.
    Error sourcesinput data; data transformation; statistical assumptions; coder or rater judgement
    Certainty limitsCertainty drops when training and target documents differ in period or source (indirectness), when rare categories have few examples (imprecision) and when human labels are unreliable (risk of bias).

    Related techniques

    • should follow CK-04 Gold-standard validation sample (ground truth set; human-coded validation set): human-coded labels are needed to train and score
    • pairs with CK-05 Out-of-sample validation (train and test split; k-fold cross-validation; bootstrap; permutation test): out-of-sample testing gives an honest error estimate
    • pairs with CK-14 Data leakage audit (train-test contamination check; model information sheet): a leakage audit checks that test items did not shape the classifier
    • substitutes for MM-08 LLM coding and zero-shot classification of text (LLM annotation; LLM-assisted deductive coding; few-shot classification; natural language inference classification): when many labelled examples exist and the volume class is needs automation

    Evidence and tag basis

    Tested. Supervised learning outperformed dictionaries on a number of criteria (2021). Fine-tuning a natural language inference model on 500 texts matched classical models trained on about 5,000 (2024). Both are abstract-level findings. (Barberá et al. 2021 via EconPapers; Laurer et al. 2024 via EconPapers; Grimmer and Stewart 2013, Political Analysis)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
