    4. MM-04 Dimensionality reduction (PCA (principal component analysis); factor analysis; non-negative matrix factorisation)

    MM-04 Dimensionality reduction (PCA (principal component analysis); factor analysis; non-negative matrix factorisation)

    Replace many correlated numeric fields with a few components and produce loadings, explained variance and a score per record.

    Measure and modelEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Replaces many correlated numeric fields with a few components that capture most of the variance. Artefact: loadings, explained variance ratio and scores per record. Read loadings to name components and explained variance to choose their number.

    When to use it

    Use when there are many correlated numeric variables and you want a smaller set of dimensions to read or model.

    When it does not fit

    Fits correlated fields with linear structure. PCA centres but does not scale, so large-variance fields dominate unless standardised. Misfit: the first components explain little variance, or loadings cannot be interpreted.

    Result format

    The result has a table of loadings for each component, the explained variance ratio for each component, and a score for each record. It names each component from its loadings and states how many components were kept and why.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents plausible names for components without checking loadings.
    Error sourcesinput data; data transformation; statistical assumptions
    Certainty limitsCertainty drops when variables are not standardised (risk of bias), when components are named without reading loadings (indirectness) and when results change with the number of components kept (inconsistency).

    Related techniques

    • should follow PE-04 Data profiling and rule-based validation (data audit; data quality assessment; edit checks): unit and scale problems distort the components
    • pairs with MM-03 Clustering of records (k-means; hierarchical (agglomerative) clustering; DBSCAN (density-based spatial clustering of applications with noise); HDBSCAN (hierarchical DBSCAN)): components can be used as input to clustering of records
