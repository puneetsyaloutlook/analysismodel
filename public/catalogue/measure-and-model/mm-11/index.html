    MM-11 Framing analysis at scale (frame detection; issue framing; media frames coding)

    Identify which aspects of an issue each text emphasises using a defined frame scheme and produce frame labels with frame shares by source and period.

    Measure and modelEvidence: TestedPhase: analyseClaim ceiling: describe

    What it does

    Identifies which aspects of an issue a text emphasises, using a defined frame scheme. Artefact: frame labels and frame shares by source and period. Read changes in the dominant frame and the frames that are absent.

    When to use it

    Use when you want to know how different sources or periods present the same issue, using a set of frames agreed beforehand.

    When it does not fit

    Needs a defined frame set that coders agree on. Misfit: frames invented after reading, so the scheme fits the finding.

    Output specification

    The result has a frame label for each text and a table of frame shares by source and period. It names the changes in the dominant frame and the frames of the scheme that are absent.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureAssigns a frame to every document, including those that have none.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsCertainty drops when coders disagree on frames (risk of bias), when the frame set was fitted to the texts (indirectness) and when some frames are rare (imprecision).

    Related techniques

    • pairs with CK-01 Inter-coder agreement statistics (percentage agreement; Cohen's kappa; weighted kappa; Scott's pi; Fleiss' kappa; Krippendorff's alpha; intercoder reliability testing): agreement statistics test whether coders apply the frame set the same way
    • substitutes for HE1-15 Content analysis (conventional, directed and summative): when a fixed frame scheme exists and the volume class is needs automation

    Evidence and tag basis

    Tested. Frame detection was one of four tasks on which ChatGPT beat crowd workers in a 2,382-tweet study. The content of the Media Frames Corpus was not confirmed. (Gilardi et al., arXiv 2303.15056)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
