    FQ-06 SMART check (specific, measurable, achievable, relevant, time-bound)

    Checks that an objective or question names a scope, a measure, a feasible target and a time limit, and produces the draft rewritten with each criterion answered.

    Frame the questionEvidence: PracticeQuestion technique, runs in step 5.1Strongest statement: describe

    What it does

    Checks that an objective or question names a scope, a measure, a feasible target and a time limit. Artefact: the draft rewritten with each criterion answered; a criterion that cannot be answered is a gap in the framing.

    When to use it

    Use when a goal or question is drafted and you want to confirm it can be measured and finished before work begins.

    When it does not fit

    The work is exploratory and no measure can be set in advance. It was designed for management objectives, so its use on research questions is an extension.

    Result format

    The result is the draft objective or question rewritten with one answer for each of the five criteria: specific, measurable, achievable, relevant and time-bound. Any criterion that cannot be answered is named as a gap in the framing.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureRewrites the question so that every criterion appears answered when the target or time limit has been invented.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsThe criteria test form, not whether the question is worth asking; invented targets lower certainty by indirectness.

    Related techniques

    • should follow FQ-01 PICO family (population, intervention, comparison, outcome; variants PICOT, PEO, PICo, SPIDER): A structured question gives the draft that the criteria are applied to
    • pairs with FQ-02 Decision-first framing (decision-focused or value-focused question design): Decision-first framing supplies the options that the measure must be able to separate

    Evidence and tag basis

    Practice. The source page reports criticism that the original lacks a clear theoretical basis and that evidence for specific goals is mixed. (Wikipedia, SMART criteria)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
