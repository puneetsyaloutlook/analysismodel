    FQ-02 Decision-first framing (decision-focused or value-focused question design)

    Starts from the decision to be made and works back to a list of questions, each tagged with the option it could change.

    Frame the questionEvidence: UnconfirmedQuestion technique, runs in step 5.1Strongest statement: describe

    What it does

    Starts from the decision to be made and works back to the evidence that would change it. Artefact: a list of questions, each tagged with the option it could change. Questions that change no option are out of scope.

    When to use it

    Use when a decision is pending and you want to ask only the questions whose answers could change which option is chosen.

    When it does not fit

    No decision exists (pure description), or a 'yes' and a 'no' answer lead to the same action.

    Result format

    The result is a list of questions, each tagged with the option it could change. It names the decision the questions serve and lists separately the questions that change no option and are therefore out of scope.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents decision options or decision criteria that the decision maker has not stated.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsRisk of bias if the decision maker states the options or criteria incompletely; indirectness if the question list drifts from the actual decision.

    Related techniques

    • pairs with DM-01 MECE decomposition and issue tree (mutually exclusive, collectively exhaustive; logic tree, problem tree; related: work breakdown structure): An issue tree can split the decision question into sub-questions
    • pairs with FQ-06 SMART check (specific, measurable, achievable, relevant, time-bound): Criteria checking confirms each retained question has a measure and a time limit
