    FQ-02 Decision-first framing (decision-focused or value-focused question design)

    Starts from the decision to be made and works back to a list of questions, each tagged with the option it could change.

    Frame the questionEvidence: DocumentedQuestion technique, runs in step 5.1Strongest statement: describe

    What it does

    Starts from the decision to be made and works back to the evidence that would change it. Artefact: a list of questions, each tagged with the option it could change. Questions that change no option are out of scope.

    When to use it

    Use when a decision is pending and you want to ask only the questions whose answers could change which option is chosen.

    When it does not fit

    No decision exists (pure description), or a 'yes' and a 'no' answer lead to the same action.

    Result format

    The result is a list of questions, each tagged with the option it could change. It names the decision the questions serve and lists separately the questions that change no option and are therefore out of scope.

    Method steps

    1. State the decision to be made and the options now on the table.
    2. List the fundamental objectives: what the decision is meant to achieve, written before any option is judged.
    3. List the questions the analysis could ask.
    4. Tag each question with the option or options its answer could change, and the objective it bears on.
    5. Flag the questions that change no option. These are candidates to drop.
    6. Where the objectives suggest options not yet on the list, add them and tag the questions against them.
    7. Write the result: the list of questions, each tagged with the option it could change.

    Steps drawn from: Keeney's value-focused thinking, which puts values before alternatives (Keeney, MIT Sloan Management Review; Keeney, Making value-focused decisions, Cambridge University Press). The tagging of questions follows the result format of this row.

    Evidence and tag basis

    Documented. Keeney's value-focused thinking starts from the objectives that give a decision its meaning, and uses them to find hidden objectives, direct the collection of information and create better alternatives. A value-focused decision process begins with three front-end components: state the decision problem, identify the values, and create alternatives. (Keeney, Creativity in decision making with value-focused thinking, MIT Sloan Management Review; Keeney, Making value-focused decisions, Cambridge University Press) Using the objectives to tag survey or analysis questions is an application of the method, with no test found.

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
