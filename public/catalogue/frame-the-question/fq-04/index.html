    FQ-04 Reframing and issue redefinition (changing the level of analysis or baseline; five-step issue redefinition)

    Restates the question at another level, with another baseline, or by rephrasing, broadening, narrowing and reversing it, and produces answers side by side.

    Frame the questionEvidence: PracticePhase: frameClaim ceiling: describe

    What it does

    Restates the question at another level (individual, organisation, system), with another baseline, or by rephrasing, broadening, narrowing and reversing it. Artefact: answers side by side; an answer that reverses between frames depends on wording.

    When to use it

    Use when the answer may depend on how the question is worded or at what level it is asked.

    When it does not fit

    The alternative frames differ only in wording. A reversal between frames is a finding about the topic, not a failure of the technique.

    Output specification

    The result states the question in each frame used (such as individual, organisation and system level, a different baseline, or a rephrased, broadened, narrowed or reversed form) and places the answer to each frame side by side. It names the answers that reverse between frames and says that these depend on wording.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureProduces frames that differ only in wording, so that the answers agree for a trivial reason.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsInconsistency is reported when answers reverse between frames; limited evidence that deliberate reframing improves research quality.

    Related techniques

    • pairs with FQ-05 Multiple mental models (applying explicit models from several fields to one topic): Several explicit models test whether the answer depends on the model as well as the wording
    • pairs with DM-16 Levels-of-analysis models (Marr's three levels, micro, meso and macro levels): Levels of analysis give a defined set of levels for the reframing

    Evidence and tag basis

    Practice. The framing effect is documented in psychology (in the Asian disease problem, 72 per cent chose the certain option when outcomes were framed as lives saved and 78 per cent chose the risky option when framed as deaths) (Wikipedia, Framing effect (psychology)). Deliberate reframing as a research technique was not sourced; issue redefinition is named in the UK handbook (UK Red Teaming Handbook).

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
