    CM1-15 Gap analysis

    Compares current with desired performance, producing a prioritised list of gaps and the means to close each.

    CompareEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Compares current with desired performance. Artefact: a prioritised list of gaps and the means to close each; read the largest or most critical gaps.

    When to use it

    Use when a user asks how far a current state is from a target and what to do first to close the distance.

    When it does not fit

    No clear target state exists, or the benchmark is unsuitable.

    Result format

    The result is a prioritised list of gaps, each row naming the current performance, the desired performance, the size of the gap and the means to close it. The largest or most critical gaps come first, and the result ends by naming them.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureInvents a target state when none is given and ranks gaps by how easy they are to describe.
    Error sourcesinput data; source selection; coder or rater judgement
    Certainty limitsCertainty drops when the target is not evidenced (indirectness) or the current state rests on self-report (risk of bias).

    Related techniques

    • should follow CM1-12 Benchmarking and peer comparison (best-practice comparison, competitor analysis): benchmarking supplies an external target state
    • pairs with AO-12 Multi-criteria decision analysis (MCDA): weighted criteria make the priority order of gaps explicit
