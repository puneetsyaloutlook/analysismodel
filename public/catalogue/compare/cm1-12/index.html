    CM1-12 Benchmarking and peer comparison (best-practice comparison, competitor analysis)

    Compares an organisation processes and metrics with those of peers or leaders, producing a gap table of own against benchmark performance.

    CompareEvidence: DocumentedPhase: analyseClaim ceiling: describe

    What it does

    Compares an organisation's processes and metrics with those of peers or leaders. Artefact: a gap table of own against benchmark performance; read relative position and practices to adopt.

    When to use it

    Use when a user asks how an organisation performs against peers or best practice, or which practices a leader uses that it lacks.

    When it does not fit

    Metrics are defined differently across organisations or over time, or the function (human resources, information technology) is hard to compare directly.

    Output specification

    The result is a gap table with one row per process or metric, giving the organisation's own performance, the benchmark performance of the peers or leaders, and the gap. It names the organisation's relative position and the practices to adopt.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureCompares figures whose definitions differ between organisations and presents the gap as real.
    Error sourcesinput data; source selection; data transformation
    Certainty limitsCertainty drops when metric definitions differ between organisations or years (inconsistency), when peers are not comparable (indirectness), or when published metrics are selectively reported (reporting bias).
