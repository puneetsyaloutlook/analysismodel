    CM1-04 Concomitant variation and method of residues (Mill)

    Infers a link when a factor varies with the effect (concomitant variation) or attributes the unexplained part of an effect to the remaining circumstances (residues), producing a co-movement pattern or a residual.

    CompareEvidence: DocumentedPhase: analyseClaim ceiling: associate

    What it does

    Concomitant variation infers a link when a factor's variation tracks variation in the effect; residues attributes the unexplained part of an effect to the remaining circumstances. Artefact: a co-movement pattern or a residual.

    When to use it

    Use when a user has an effect that varies in degree and asks whether it moves with a candidate factor, or what is left once known causes are removed.

    When it does not fit

    Covariation is read as proof, which cannot rule out alternative explanations, or the causes of the other parts of the effect are not established.

    Output specification

    The result is either a co-movement pattern showing how variation in a factor tracks variation in the effect, or a residual showing the part of the effect left unexplained once known factors are removed and the remaining circumstances it is attributed to. It states which of the two it gives.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureReports a correlation computed in text with arithmetic slips, and reads co-movement as a cause.
    Error sourcesinput data; statistical assumptions; data transformation
    Certainty limitsCertainty drops when a third factor could drive both series (indirectness), when there are few observations (imprecision), or when the other causes in a residues argument are not established.

    Related techniques

    • pairs with TC-05 Subgroup and Simpson's paradox check (stratified reanalysis; confounding check; collapsibility check): a subgroup check tests whether the co-movement reverses within groups
    • should follow MM-01 Exploratory data analysis with plots and distribution checks (EDA (exploratory data analysis); summary statistics; Q-Q plot; scatterplot matrix): plots and distribution checks show whether the relationship is plausible before it is read
