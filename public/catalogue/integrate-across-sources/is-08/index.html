    IS-08 Joint display

    Places quantitative and qualitative results in one table, figure or matrix with shared row labels and produces a matrix that shows where the strands agree, expand each other or conflict.

    Integrate across sourcesEvidence: DocumentedPhase: analyseClaim ceiling: describe

    What it does

    Places quantitative and qualitative results in one table, figure or matrix with shared row labels. Artefact: a matrix. Read the rows where the strands agree, expand each other or conflict.

    When to use it

    Use when you need to show side by side what the numbers and the narrative say about each topic.

    When it does not fit

    Fits when both strands map to the same row labels. Misfit: forced labels that hide differences. The source gives no detailed method for building the rows.

    Output specification

    The result is one table or matrix with shared row labels, where each row holds the quantitative result and the qualitative result for that label side by side. It adds a column marking each row as agree, expand or conflict, and it names the rows in which the strands conflict.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureWrites matrix cells that summarise both strands in the same words, which hides conflict.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsCertainty drops when the row labels are forced and when the strands were analysed to different standards.

    Related techniques

    • should follow IS-07 Convergent comparison of qualitative and quantitative results (convergent parallel design; concurrent triangulation): the merge of results supplies the content of the rows

    Evidence and tag basis

    Documented. Defined in the source as a visual means to draw out new insights. (Fetters, Curry and Creswell 2013, via core.ac.uk)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
