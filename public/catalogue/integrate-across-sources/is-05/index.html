    IS-05 Truth discovery with source reliability weighting (truth finding; source reliability estimation)

    Jointly estimates the true value of each object and the reliability of each source from conflicting claims and produces a truth per object and a weight per source.

    Integrate across sourcesEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Jointly estimates the true value of each object and the reliability of each source from conflicting claims. Artefact: a truth per object and a weight per source. Read low-weight sources and low-confidence truths.

    When to use it

    Use when many sources make conflicting claims about many objects and you need to know which values to believe and which sources to trust.

    When it does not fit

    Fits many objects claimed by many sources. Misfit: few claims per source, correlated sources, or objects with no conflict. Most methods start from uniform weights, which behaves like voting at first, and assume a source is equally reliable on every object. Evaluation needs ground truth, which is often absent.

    Result format

    The result has a table of the estimated true value for each object with a confidence level, and a table of the reliability weight for each source. It names the low-weight sources and the low-confidence truths.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureReports source weights without a ground truth sample and treats agreement between copied sources as support.
    Error sourcesinput data; statistical assumptions; source selection
    Certainty limitsCertainty drops without ground truth to test the estimates, with dependent sources, and with few claims per source (imprecision and risk of bias).

    Related techniques

    • should follow IS-06 Source dependence and copy detection (source independence analysis): dependence between sources must be checked first
    • substitutes for IS-04 Data fusion with conflict resolution (majority voting; deciding and mediating resolution functions): when many claims per source allow reliability to be estimated

    Evidence and tag basis

    Documented. The survey groups methods as iterative, optimisation-based and probabilistic graphical model, and does not rank them. A Deep Web study found surprising inconsistency across sources it considered relatively clean (abstract only). (Li et al., A survey on truth discovery, arXiv 1505.02463; Li et al., Truth finding on the Deep Web, arXiv 1503.00303)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
