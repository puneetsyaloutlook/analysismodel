    IS-06 Source dependence and copy detection (source independence analysis)

    Estimates whether sources copy from each other so that their agreement is not counted as independent support and produces a dependence estimate for source pairs or groups.

    Integrate across sourcesEvidence: DocumentedPreparation technique, runs in step 5.2Strongest statement: describe

    What it does

    Estimates whether sources copy from each other, so that their agreement is not counted as independent support. Artefact: a dependence estimate for source pairs or groups. Read which sources should be grouped as one.

    When to use it

    Use when several sources agree and you need to know whether they are independent or share one upstream origin.

    When it does not fit

    Fits when copying leaves shared errors. Misfit: a source copies from a good source, so there are no shared mistakes to detect. Co-copying and chains are harder to detect.

    Result format

    The result is a dependence estimate for each pair or group of sources, stating how likely it is that one copies from the other. It ends with the sources that should be grouped and counted as one.

    Certainty limitsCertainty drops when copying leaves no shared errors, and when sources are few (imprecision).

    Evidence and tag basis

    Documented. In the tutorial example, two sources copy from a third, so treating them as independent would wrongly confirm everything the third provides. (Dong and Naumann, VLDB tutorial; Li et al., A survey on truth discovery, arXiv 1505.02463)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
