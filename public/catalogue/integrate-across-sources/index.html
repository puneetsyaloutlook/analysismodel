    Integrate across sources

    11 techniques.

    IDTechniquePurposeEvidence status
    IS-01Entity resolution and linking (record linkage; entity matching; entity linking; coreference resolution; blocking)Decides which records or text mentions refer to the same entity by comparing attributes, with no shared identifier required, and produces match decisions or linked clusters.Documented
    IS-02Schema matching and ontology matching (schema mapping; field mapping)Establishes which fields or concepts in different sources mean the same thing and produces a mapping table of equivalent, partly equivalent and unmapped fields.Documented
    IS-03Common data model harmonisation (OMOP (Observational Medical Outcomes Partnership) common data model; data harmonisation)Transforms source datasets into one shared structure and vocabulary so that the same analysis runs on each and produces a standardised dataset with a coverage report.Documented
    IS-04Data fusion with conflict resolution (majority voting; deciding and mediating resolution functions)Combines records on the same entity into one record, resolving conflicting values by a rule, and produces a fused record per entity with uncertain and contradictory values marked.Documented
    IS-05Truth discovery with source reliability weighting (truth finding; source reliability estimation)Jointly estimates the true value of each object and the reliability of each source from conflicting claims and produces a truth per object and a weight per source.Documented
    IS-06Source dependence and copy detection (source independence analysis)Estimates whether sources copy from each other so that their agreement is not counted as independent support and produces a dependence estimate for source pairs or groups.Documented
    IS-07Convergent comparison of qualitative and quantitative results (convergent parallel design; concurrent triangulation)Analyses qualitative and quantitative results on the same topic separately, then merges them to compare and produces a comparison of agreement, partial agreement and discordance by topic.Documented
    IS-08Joint displayPlaces quantitative and qualitative results in one table, figure or matrix with shared row labels and produces a matrix that shows where the strands agree, expand each other or conflict.Documented
    IS-09Quantitising and qualitising (data transformation)Converts one data type into the other, for example by counting coded themes, and produces a single-type dataset of frequencies or profiles.Unconfirmed
    IS-10Explanatory sequential integration (explanatory sequential design)Uses a completed quantitative result, especially an unexpected or extreme one, to choose the qualitative material read to explain it and produces an explanation linked to the numeric pattern.Documented
    IS-11Exploratory sequential integration (exploratory sequential design)Uses qualitative results to decide what is measured in a later quantitative stage and produces measures or hypotheses derived from themes.Documented
