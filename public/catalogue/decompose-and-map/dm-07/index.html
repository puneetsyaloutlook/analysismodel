    DM-07 Lens application (sorting claims by a classification lens, for example input versus outcome)

    Sorts a set of claims or measures by chosen categories, such as input or outcome, and produces a table of claims by category.

    Decompose and mapEvidence: UnconfirmedPhase: analyseClaim ceiling: describe

    What it does

    Sorts a set of claims or measures by a chosen set of categories so that mixed kinds of claim can be compared by type. Artefact: a table of claims by category; many claims in one category (inputs) and few in another (outcomes) shows that evidence of a kind is missing.

    When to use it

    Use when claims of different kinds are mixed and you want to compare them by type and see which kind of evidence is missing.

    When it does not fit

    Claims cannot be assigned reliably, or two raters assign them differently, which shows the category definitions are unclear.

    Output specification

    The result is a table of claims or measures sorted by the categories of the chosen lens, with each claim shown in one category. It gives the count in each category and names any category with few or no entries, which shows that evidence of that kind is missing.

    Failure modes and limits

    Model suitabilitymodel alone
    Typical model failureAssigns borderline claims to the most common category, which hides the weak categories that the technique is meant to expose.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsRater disagreement on category assignment lowers certainty by inconsistency; no source describes this as a named technique.
