    DM-13 System archetypes (limits to growth, shifting the burden, fixes that fail, and others)

    Matches an observed behaviour pattern to a recurring feedback structure and produces a named pattern with the loop structure to change.

    Decompose and mapEvidence: DocumentedPhase: analyseClaim ceiling: describe

    What it does

    Matches an observed behaviour pattern to a recurring feedback structure. Artefact: a named pattern; read the loop structure to change.

    When to use it

    Use when a problem keeps recurring or a fix keeps failing and you want to match it to a known feedback structure.

    When it does not fit

    Behaviour matches two archetypes equally or none. The label should follow the loop structure and not replace it.

    Output specification

    The result names the system archetype that matches the observed behaviour pattern (such as limits to growth, shifting the burden or fixes that fail). It describes the loop structure of that archetype as it applies to the case and names the loop structure to change.

    Model suitabilityhuman judgement required

    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsThe source relies mostly on one origin and gives no evidence base; a match to one archetype is a hypothesis about structure and not a test of cause.
