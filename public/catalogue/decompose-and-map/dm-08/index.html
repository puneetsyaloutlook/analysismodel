    DM-08 Two by two matrix (quadrant analysis) Also serves: Assess actors, options and risks; Project forward.

    Places items on two chosen dimensions so that each falls into one of four cells and produces a quadrant table.

    Decompose and mapEvidence: DocumentedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Places items on two chosen dimensions so that each is assigned to one of four cells. Artefact: items plotted or sorted into quadrants; read the count per quadrant and clusters near cell boundaries.

    When to use it

    Use when items can be rated on two dimensions and you want a quick sort into four groups.

    When it does not fit

    Items cluster on one axis, the two dimensions are correlated, or ratings differ between raters.

    Result format

    The result places each item in one of four quadrants defined by the two named dimensions, as a plot or a sorted list. It gives the count per quadrant and names the items close to a cell boundary.

    Method steps

    1. Choose the two dimensions and define each in one line. The choice of dimensions sets what the result can show.
    2. Choose the cut point on each dimension, for example high and low.
    3. List the items to place.
    4. Rate each item on both dimensions.
    5. Place each item in one of the four cells.
    6. Count the items in each cell and note the items close to a cell boundary.
    7. Name what each cell implies for the question. In a power and interest grid, the cells are manage closely, keep satisfied, keep informed and monitor.

    Steps drawn from: the power and interest grid as described by Nielsen Norman Group, The Open University and MITRE.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureRates items on each axis from general impressions, giving ratings that cannot be reproduced or defended.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsRater differences and the choice of dimensions lower certainty by risk of bias and inconsistency; no source evaluates the form as a general technique.

    Evidence and tag basis

    Documented. The power and interest grid plots stakeholders on two axes so that each falls in one of four quadrants, each calling for a different management strategy. It is sometimes called Mendelow's matrix. (Nielsen Norman Group, stakeholder analysis; The Open University, power interest grid; MITRE, stakeholder map and matrix)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
