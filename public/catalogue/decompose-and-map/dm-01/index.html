    DM-01 MECE decomposition and issue tree (mutually exclusive, collectively exhaustive; logic tree, problem tree; related: work breakdown structure)

    Divides a topic into sub-parts that do not overlap and together cover the whole, repeated at each level, and produces a tree.

    Decompose and mapEvidence: PracticePhase: frameClaim ceiling: describe

    What it does

    Divides a topic into sub-parts that do not overlap and together cover the whole, repeated at each level. Artefact: a tree; read gaps (missing branches), overlaps and the relative size of branches.

    When to use it

    Use when a broad topic needs to be broken into non-overlapping parts so that gaps and overlaps in coverage become visible.

    When it does not fit

    Items fit two branches, fit none, or an 'other' branch grows large. Wikipedia's example: grouping by nationality fails because some people hold two nationalities and some hold none.

    Output specification

    The result is a tree with the topic at the top and sub-parts at each level, where the branches at each level do not overlap and together cover the parent. It names any gaps (missing branches), any overlaps, and the relative size of the branches.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureProduces a tree whose branches look exclusive but overlap, or that omits an awkward branch, while asserting that it is exhaustive.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsExhaustiveness cannot be proved; an other branch that grows lowers certainty by indirectness, and the splitting rule is a source of bias.

    Related techniques

    • pairs with DM-02 Hypothesis tree (hypothesis-driven decomposition, claim decomposition): A hypothesis tree applies the same splitting to a claim and not a topic
    • pairs with FQ-02 Decision-first framing (decision-focused or value-focused question design): A decision question gives the root of the tree

    Evidence and tag basis

    Practice. Consulting practice attributed to Minto at McKinsey. Criticised as not fully exhaustive and as excluding useful redundancy; no effectiveness evidence found. (Wikipedia, MECE principle)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
