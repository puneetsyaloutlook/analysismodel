    DM-03 Morphological analysis (Zwicky box, general morphological analysis) Also serves: Project forward.

    Lists the parameters of a topic and the possible values of each, removes value pairs judged inconsistent, and produces a grid and a reduced set of consistent configurations.

    Decompose and mapEvidence: DocumentedPhase: analyseClaim ceiling: describe

    What it does

    Lists the parameters of a topic and the possible values of each, then removes value pairs judged inconsistent. Artefact: a grid and a reduced set of consistent configurations; read values that appear in all or none.

    When to use it

    Use when a topic has several dimensions with discrete options and you need the set of workable combinations without numerical data.

    When it does not fit

    Almost all combinations are judged consistent, or almost none (parameters or values poorly defined), or the number of parameters makes the space too large to prune.

    Output specification

    The result has a grid with one column per parameter of the topic and the possible values of each listed under it, and a reduced set of consistent configurations after value pairs judged inconsistent are removed. It names the values that appear in all of the consistent configurations and the values that appear in none.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureJudges value pairs inconsistent from plausibility alone without recording the reasoning, so the reduced set cannot be audited.
    Error sourcesinput data; expert opinion; language model
    Certainty limitsThe consistency judgements are expert opinion with no accuracy evidence; they lower certainty by risk of bias and imprecision.

    Related techniques

    • pairs with PJ-12 Scenario planning (intuitive logics, Shell approach): Consistent configurations can be written up as scenarios
    • pairs with PJ-13 Scenario matrix (two by two scenario axes, alternative futures analysis): A scenario matrix handles two axes where this technique handles many

    Evidence and tag basis

    Documented. Described as intended for non-quantified problems; consistency judgements are expert opinion; no accuracy evidence found. (Wikipedia, Morphological analysis (problem-solving))

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
