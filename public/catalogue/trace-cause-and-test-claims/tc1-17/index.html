    TC1-17 Sensitivity analysis (robustness check, leave-one-out)

    Re-runs an analysis under different assumptions or inclusion rules and produces a table of results by assumption showing whether the conclusion reverses.

    Trace cause and test claimsEvidence: DocumentedPhase: validateClaim ceiling: describe

    What it does

    Re-runs an analysis under different assumptions or inclusion rules. Artefact: a table of results by assumption; read whether the conclusion reverses.

    When to use it

    Use when you want to know how much a result depends on the choices made in producing it.

    When it does not fit

    Only convenient assumptions are varied.

    Output specification

    The result is a table with one row per changed assumption or inclusion rule and the result obtained under each, alongside the original result. It ends by stating whether the conclusion reverses under any row.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureVaries only convenient assumptions and reports that the result holds, or changes several assumptions at once so the cause of a change is unclear.
    Error sourcesinput data; statistical assumptions; data transformation
    Certainty limitsCertainty drops when only favourable alternatives are tried, when choices are not listed in advance, or when the original analysis is itself unsound.

    Evidence and tag basis

    Documented. The Cochrane Handbook advises it because meta-analysis results depend on many judgements. (Cochrane Handbook, chapter 10)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
