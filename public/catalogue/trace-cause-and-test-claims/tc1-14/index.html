    TC1-14 Coherence correction and averaging of probability judgements

    Adjusts each analyst's probabilities on mutually exclusive hypotheses so they sum to one, averages across analysts, and produces a corrected aggregated judgement.

    Trace cause and test claimsEvidence: TestedPrimary technique, runs in step 5.3Strongest statement: describe

    What it does

    Adjusts each analyst's probability judgements so that those on mutually exclusive hypotheses sum to one, and averages across analysts. Artefact: a corrected, aggregated judgement.

    When to use it

    Use when several analysts have given probability estimates on the same set of hypotheses and you want one combined, internally consistent judgement.

    When it does not fit

    Judgements are not on mutually exclusive, exhaustive hypotheses, or the judges share the same bias.

    Result format

    The result is a table with one row per hypothesis and one column per analyst, showing each analyst's probability as given and as corrected so that the probabilities on mutually exclusive hypotheses sum to one. It ends with a corrected, aggregated probability for each hypothesis, averaged across analysts.

    Failure modes and limits

    Model suitabilitymodel plus code
    Typical model failureAverages judgements that share one source or bias, or normalises probabilities over a hypothesis set that is not exhaustive.
    Error sourcesinput data; expert opinion; statistical assumptions
    Certainty limitsCertainty drops when analysts are not independent, when hypotheses overlap or omit possibilities, or when the evidence comes from one small homogeneous laboratory sample (indirectness).

    Related techniques

    • should follow TC1-13 Analysis of competing hypotheses (ACH): the matrix supplies the hypotheses on which judgements are collected
    • pairs with TC1-15 Bayesian updating (likelihood reasoning, likelihood ratio, Bayes factor): Bayesian updating gives coherent probabilities from a single analyst

    Evidence and tag basis

    Tested. Reported to cut error by about 35 per cent (coherence correction) and about 61 per cent (averaging all 50 corrected judgements) in one laboratory task. Small homogeneous sample; attribution of the paper is unresolved. (Cambridge Core paper on what works and what fails in improving analysts' accuracy)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
