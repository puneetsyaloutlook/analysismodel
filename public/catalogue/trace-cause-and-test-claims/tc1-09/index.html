    TC1-09 Logic model and theory of change

    Maps the expected causal chain from inputs to outcomes with the assumption behind each step and produces a logic model or theory of change.

    Trace cause and test claimsEvidence: DocumentedPhase: frameClaim ceiling: describe

    What it does

    Maps the expected causal chain from inputs to outcomes with the assumptions behind each step. Artefact: a diagram or narrative of if-then links; read the weakest assumption and the strength of evidence at each link.

    When to use it

    Use when you need to set out how a program is meant to produce its outcomes and where its weakest assumptions are.

    When it does not fit

    Outcomes may result from processes outside the program so that success is wrongly credited to it. Models vary widely in components.

    Output specification

    The result is a diagram or narrative of if-then links from inputs through to outcomes, with the assumption behind each link written beside it and the strength of evidence at each link stated. It has a register of the assumptions and names the weakest one.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureFills the links with generic activities and outcomes and states assumptions that cannot be tested.
    Error sourcesinput data; source selection; expert opinion
    Certainty limitsThe model is a stated theory and carries no evidential weight until each link is tested. Certainty falls further when the documents are written by the program owners.

    Related techniques

    • pairs with TC1-10 Contribution analysis: contribution analysis tests each link of the model against evidence
    • pairs with TC1-12 Process evaluation and impact evaluation: process evaluation checks the delivery steps of the model

    Evidence and tag basis

    Documented. The Magenta Book defines a theory of change as a synthesis of existing evidence; the logic model page gives inputs, activities, outputs and outcomes. (Magenta Book, central government guidance on evaluation; Wikipedia, Logic model)

    Tag basis: input profile inference; selection inference; sequencing inference; robustness inference. All tag values are inference unless a source is named.
