    TC1-08 Confounder identification with directed acyclic graphs (adjustment sets, backdoor criterion)

    Draws assumed causal links as a directed acyclic graph and produces a diagram and an adjustment set of variables to include and to leave out.

    Trace cause and test claimsEvidence: UnconfirmedPrimary technique, runs in step 5.3Strongest statement: estimate the effect of an action

    What it does

    Draws assumed causal links to decide which variables to adjust for and which to leave alone. Artefact: a diagram and an adjustment set.

    When to use it

    Use when you must decide which variables to control for before estimating an effect and the causal links can be defended from subject knowledge.

    When it does not fit

    Important common causes are unmeasured, or a collider or mediator is adjusted for, which can add bias.

    Result format

    The result has a diagram of the assumed causal links between the variables and an adjustment set naming the variables to adjust for and the variables to leave alone. It also has a register of the causal assumptions the diagram depends on.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureDraws links to match the data at hand and not prior knowledge, or includes a collider or mediator in the adjustment set.
    Error sourcesinput data; expert opinion; coder or rater judgement
    Certainty limitsCertainty drops when links are untested, when relevant common causes are unmeasured, or when experts disagree on the graph (risk of bias). The ceiling is estimate an intervention effect because the graph states what must be adjusted for, and the estimate comes from another technique.
