    TC1-28 Dimensional and unit checks

    Checks that both sides of a relation have the same units and produces a unit balance in which a mismatch flags an error in the derivation.

    Trace cause and test claimsEvidence: DocumentedPhase: validateClaim ceiling: describe

    What it does

    Checks that both sides of a relation have the same units. Artefact: a unit balance; a mismatch indicates an error in the derivation.

    When to use it

    Use when a formula or calculation has been produced and you want to catch errors in its units before relying on the number.

    When it does not fit

    A match is read as proof; numerical factors are invisible to the check.

    Output specification

    The result is a table with one row per relation, giving the units on each side and the unit balance for the relation. It lists any mismatch as an error in the derivation, and says where the mismatch occurs.

    Model suitabilitymodel plus code
    Typical model failureTreats a matching unit balance as proof of correctness, or overlooks mixed units such as per cent against percentage points.
    Error sourcesinput data; data transformation
    Certainty limitsA match shows only that units agree. Logic errors and wrong numerical factors remain unchecked.
