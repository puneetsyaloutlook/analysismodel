    CH-14 Structured brainstorming

    Generates and clusters many ideas about a focal question before any critique and produces clustered, prioritised ideas.

    ChallengeEvidence: DocumentedPhase: frameClaim ceiling: describe

    What it does

    Generates and clusters many ideas about a focal question before any critique. Artefact: clustered, prioritised ideas; read the outlier ideas that were set aside.

    When to use it

    Use when you need a wide set of ideas, causes or options on a focal question before narrowing.

    When it does not fit

    Individuals cannot escape their own biases, and productivity falls after about 60 to 90 minutes.

    Output specification

    The result is a set of ideas about the focal question, grouped into clusters with a name for each cluster, and a prioritised order of the ideas. It also lists the outlier ideas that were set aside, so they can be read.

    Failure modes and limits

    Model suitabilityhuman judgement required
    Typical model failureProduces a long list of similar ideas from one view and clusters them by wording and not by meaning.
    Error sourcesinput data; coder or rater judgement; language model
    Certainty limitsNo effectiveness evidence was read and the sources give different group sizes; idea sets reflect the participants and carry risk of bias.

    Related techniques

    • pairs with CH-15 Group process safeguards (everyone speaks once before anyone speaks twice, mindguarding): Group safeguards keep individual views independent before ideas are pooled
    • pairs with TC1-02 Fishbone diagram (Ishikawa diagram, cause and effect diagram): A fishbone diagram groups brainstormed causes of one problem

    Evidence and tag basis

    Documented. The two sources give different group sizes; no effectiveness evidence was read. (CIA Tradecraft Primer (2009); UK Red Teaming Handbook)
