    ANLYSIS

    ANLYSIS is a catalogue of analytical techniques and a process for choosing and running them. It takes a request and some material, chooses the analytical techniques that can run on that material, runs them in order, checks their findings and combines them into one answer with a confidence label for each conclusion.

    The name is ANLYSIS in running text. ANLYSIS.work is the address of this site.

    The catalogue holds 236 techniques in 12 families. This site documents the process and the catalogue. It is generated from the design document, the schema and the catalogue file in the repository, so it changes only when those change.
