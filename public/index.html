    startthat.work

    startthat.work is a catalogue of analytical techniques and a process for choosing and running them. It takes a request and some material, chooses the analytical techniques that can run on that material, runs them in order, checks their findings and combines them into one answer, with the conclusions grouped by how well each is supported.

    The name is startthat.work, which is also the address of this site. The skill that runs the process is named analysis.

    The catalogue holds 304 techniques in 19 families. This site documents the process and the catalogue. It is generated from the design document, the schema and the catalogue file in the repository, so it changes only when those change.

    Process at a glance

    The process turns a request and some material into one answer. The user is asked only at the decision points. Each step links to the page that explains it.

    StepWhat happens
    1. IntakeThe user's input becomes a brief. Gaps become questions to the user.
    2. Rule out techniquesEach technique is tested against the brief. Techniques that cannot run on the material are removed. The rest are eligible.
    3. Choose analysis techniquesThe model reads a list of the eligible analysis techniques and chooses at most 10, with a reason for each. Conclusion and report techniques are not on the list.
    4. Plan analysis sequenceThe chosen techniques are placed in four named groups in running order, each technique with a description of what it does and a note of whether it needs an additional source. Preparation techniques and checks are added.
    5. Run the techniques5.1 Examine the question. 5.2 Prepare the material, including any additional sources and, for parts with scope topic, an evidence base. 5.3 Analyse the material.
    6. Check the findingsVerification and challenge techniques run on the findings. The library checks are applied to each result.
    7. Combine the findingsThe findings become conclusions. Each conclusion gets a confidence label and a one-line reason. The model also chooses and applies up to 3 conclusion techniques.
    8. AnswerThe model chooses and applies up to 4 report techniques. The answer is given with a list of what it is based on. The user can ask for a follow-up round.

    Techniques at a glance

    The 304 techniques are in 19 families. A family groups techniques by what they do for a request. The techniques page explains how to read a technique and lists them all.

    FamilyTechniquesWhat the family is for
    Frame the question6Turn a vague topic into a clear question, before any analysis starts.
    Decompose and map21Break a topic into parts and show how the parts relate.
    Compare17Set cases, periods or groups side by side to see what differs.
    Trace cause and test claims34Look for causes, and test whether a claim holds.
    Handle evidence29Judge how far to trust sources, and prepare them for use.
    Project forward25Estimate what may happen next.
    Assess actors, options and risks19Work out who is affected, what the choices are and what could go wrong.
    Challenge15Test a conclusion by arguing against it.
    Prepare and extract14Get the material ready, so that counts and themes describe what you think they do.
    Measure and model16Analyse records with statistics and models.
    Integrate across sources11Combine sources that overlap or disagree.
    Check extracted results29Check results that came from coding or extraction, including model output.
    Combine findings into conclusions9Turn the findings of several techniques into stated conclusions.
    State confidence and uncertainty12Say how sure each conclusion is, in words, numbers or both.
    Structure the written answer8Arrange the conclusions so that a reader finds the answer first.
    Design the display15Choose and build charts and graphics that show the finding.
    Display risk and uncertainty9Show how uncertain an estimate or a risk is, so a reader reads it correctly.
    Recommend and tailor to the audience10Turn conclusions into recommendations for a named audience.
    Hold the report to its evidence5Check that the written answer says no more than the findings support.
